# HDMI FPGA 工程

工程入口：[v3_hdmi_top.gprj](v3_hdmi_top.gprj)；顶层：v3_hdmi_top；器件：GW5AST-LV138PG484AC1/I0。

## 模块组织

- rtl：输入采样、事件接口、32 复音、8 路物理弦、效果器、曲谱和 HDMI。
- src：工程使用的辅助模块。
- constraints：引脚位置、I/O 属性与时序约束。
- sim：模块及整机仿真用例、固定输入向量。
- scripts：综合、约束准备和构建辅助脚本。

v3_hdmi_top 定义板级接口与功能参数，av_hdmi_top 连接输入、音频和显示子系统。手动按键和歌曲时间线产生统一音符事件，进入声部库；合成采样经过效果器后送至 PT8211，演奏状态和音频图形送至 HDMI 面板。

## 当前配置

32 复音与 8 路物理弦启用；旧 DDS 与加法合成关闭。HDMI 使用底板接口，输出 800×600 @56.25 Hz，800×480 面板居中。顶层 31 个引脚，UART 115200；音频由 PT8211 输出。

HDMI 像素时钟为 36 MHz，串化时钟为 180 MHz。FCLK 连续运行，启动复位保持 16 个像素时钟，在像素时钟下降沿释放。合成引擎部分状态使用半速使能，DAC 的 1024 拍采样帧节拍保持不变。
