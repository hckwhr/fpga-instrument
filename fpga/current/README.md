# 当前 HDMI FPGA 工程

工程入口：v3_hdmi_top.gprj；顶层：v3_hdmi_top；器件：GW5AST-LV138PG484AC1/I0。

本目录为最新已烧录版本的源文件快照。HDMI 使用底板接口，800×600 @56.25 Hz；800×480 面板居中。31 个顶层引脚、4 个时钟；UART 115200；音频仍使用 PT8211，HDMI 仅输出视频。

本版串化 FCLK 连续运行，启动复位保持 16 个像素时钟并在下降沿释放。物理层模型已覆盖 12 个复位相位和提前释放负向控制。源文件、约束和测试保留构建时原貌。
