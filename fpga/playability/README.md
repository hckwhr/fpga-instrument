# 压力键演奏与曲目指引

独立 V5 键盘工程，保留 32 复音、8 路物理弦、自定义键位、录音回传、HDMI 和 C18 按住电平。入口为 `v3_hdmi_top.gprj`。

- 压力键 DDS/钢琴声部支持拨弦和按住，拨弦短按仍完成起音与自然衰减。
- 单键旋律支持滑音，多键和弦不继承另一键音高。
- 表情菜单选择原声、滑音、颤音；效果菜单选择关闭、混响、延迟等。
- 手动演奏用黄色指示实体键；曲目当前音符用青蓝色指引。根据实际音高与八度匹配，支持钢琴白键和自定义布局；超出音域不亮错误键，重复映射提示最左匹配键。
- 小智通过带编号的点歌命令明确选择小星星或欢乐颂，需配套 ESP 固件。

音频使用既有 PT8211 格式，音频帧间隔 1024 拍；本轮不改变音频协议。琴弦继续使用物理模型，拨弦/按住修改针对 DDS/钢琴事件路径。

## 构建

复制本目录到独立 ASCII 路径，运行 `sim/run_dynamic_regression.ps1 -Jobs 12`（150 项）和 `sim/run_hdmi_phy.ps1`（3 项官方模型）。综合后，从成功日志取得实际生成的 `.vg` 路径，显式传给约束准备脚本：

```powershell
./scripts/prepare_performance_constraints.ps1 -Netlist ./impl/gwsynthesis/project.vg
```

上例文件名仅为示例，以本次综合日志为准。脚本检查共同 CE、精确端点集合与负向用例；不扩大例外范围。之后以 place3/route2 运行 P&R。

本目录是提交版唯一的生产 FPGA 工程，对应已写入板卡的功能实现。实际测试与时序结果见 [实施记录](../../artifacts/playability/README.md)。
