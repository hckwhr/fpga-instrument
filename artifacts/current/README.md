# FPGA 工程输出

| 目录或文件 | 内容 |
| --- | --- |
| pnr/project.fs | FPGA 配置文件 |
| pnr/project.rpt.txt、project.rpt.html | 资源与实现报告 |
| pnr/project.pin.html | 引脚分配报告 |
| pnr/project_tr_content.html | 时序分析报告 |
| pnr/project.power.html | 功耗分析报告 |
| synthesis/project.vg | 实施网表 |
| synthesis/project_syn.rpt.html | 综合报告 |
| applied.cst、applied.sdc | 引脚与时序约束副本 |
| logs | 构建与仿真工具输出 |
| programming | 下载工具输出 |

源码见 [FPGA 工程](../../fpga/current/README.md)，整体设计见 [工程原理与结构](../../docs/ARCHITECTURE.md)。
