# 上位机力度与低音平衡验证

`validation.json` 为本轮验证范围；`app-smoke.json` 与 `desktop-smoke.json` 为实际自动化输出。BLE/FPGA 使用模拟设备，没有新输出的实物听感验收。

`dynamics-verification.json` 为同一份模型识别缓存的力度算法前后对照，不重新运行模型，验证音符数、音高、时刻、容量和力度趋势。`first30ModelWindow` 对应用户确认的前 30 秒独立模型窗口；`secondSong` 对应整曲识别后截取前 30 秒，二者模型边界不同。

`recording-comparison.json` 将用户的录音与旧候选前 30 秒曲谱做谐波模板对齐，用于判断整体速度趋势；未取得板端 RAM 曲谱快照。相关分数不是保真度、识别准确率或主观音质评分。

仅收录统计和说明，原曲、用户录音、逐帧模型输出、音符和曲谱库均留在本机。方法、实现和复测步骤见 [优化记录](../../docs/伴奏力度与低音平衡优化_20261024.md)。
