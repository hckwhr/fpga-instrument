# 节奏舞台与录音按钮修复

本次仅更新上位机，不修改 FPGA RTL、ESP32 固件或已烧录位流。

## 录音按钮

旧界面以 `DeviceSession.busy` 直接控制“开始录音”等按钮的 disabled 状态。自动跟随每 1.5 秒查询一次 STATUS，音频快照也占用同一连接，所以按钮会随查询变灰、恢复；点击恰好落在禁用窗口时不会产生操作。此外，未手动读取设备设置时，录音按钮始终禁用。

现在连接正常即可点击开始录音。首次使用自动查询 PERF1 支持，收到有效应答才继续开始。若其他通信正在进行，显示等待状态，最多等 12 秒，不中断已有传输。等待及录音期间，自动状态查询和音频快照让出通信；既有独占协议仍生效，不会并发发送上传与录音数据。重复点击不重复开始，断线、状态未知及准备期间离开页面不会静默续发录音请求。

这解决的是界面无法点击与周期闪烁。真实设备的无线吞吐、录音音质和扬声器输出未在本次测试中实测，不将界面回归结果替代硬件验证。

## 节奏舞台

根据用户提供的透视演奏截图改为中央近宽远窄的 12 轨舞台，宽屏左侧为得分和连击，右侧为曲谱、速度和练习方式。保留播放器主题背景，手机竖屏触键按 01—12 分两排。

键位固定为 C 大调白键或 C4—B4 半音阶，换曲不重新排序。曲谱含未映射音高时明确拒绝，不删音或折叠八度。轨道、音符、尾迹和节拍线共用投影。此阶段仍为电脑/触屏本机练习；实体键回传、RGB 指引与电脑经 BLE 控制 FPGA 发声尚未实现，不能把本机 Web Audio 声音当作 FPGA 输出。
