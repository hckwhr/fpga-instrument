# 灵弦：项目展示与求职材料

推荐项目名：**灵弦——基于 FPGA 的实时多音色合成与交互演奏系统**。

这个项目适合作为 FPGA / 数字 IC 前端 / 嵌入式系统岗位的主要项目。最值得讲清的是：独立声部如何调度、异步通信如何落到确定的板端动作、优化后如何证明功能和时序。上位机和 Android 应用体现系统完整度，投递 FPGA 岗位时不必占据简历的大部分篇幅。
