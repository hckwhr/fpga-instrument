# 八路动态物理琴弦与满载声部替换

## 范围与基线

基于已永久烧录、用户已确认设置界面正常的 `requirements_ui_20261001`。本轮实现用户确认的八路动态物理琴弦、尾音衔接、实际声部显示，并同步优化 32 路 DDS 满载替换。基础/拓展双页分类继续保留。

硬件锁定 Tang Mega 138K，SOM30354 + Dock31005，GW5AST-138C / GW5AST-LV138PG484AC1/I0，Gowin V1.9.12.03。沿用 49.152 MHz 音频时钟、每 1024 时钟一次采样（标称 48 kHz）、33.333 MHz LCD 像素时钟，以及原 PLL、引脚、CST/SDC、PT8211 接口。此次没有新增硬件输入。

## 行为与操作

1. S2 进入设置，页签上 KEY2 选择“拓展要求”；KEY0 移到“八弦建模”，KEY2 选择琴弦，S2 返回演奏。
2. 基础页选择“拨弦”“和弦”，力度先用 96、音效先用“原声”。KEY0/1/2 仍对应 I/IV/V 四音和弦；第四音为半力度的高八度根音。
3. 单次和弦使用四路；趁尾音未结束再按另一个键，分配另外四路，主画面显示最多 `08/08`。有空位时旧和弦保持独立反馈运算，不重新初始化。
4. 八路已满时，优先释放状态，再按声音电平选择较弱的可替换声部。被选声部最多用 32 个采样淡出，然后重填弦存储并淡入新音；其余声部继续运行。
5. “单音”键法下，三个键分别触发根音、二度、三度，三键同时按下仍附加高八度根音。连续按同一键也会分配新的槽位。
6. “按住”琴弦松键后施加阻尼，松键状态锁存到该次音符；重按同一键不会解除旧音阻尼。琴弦仍是一次拨动后自然衰减的模型，不是持续激励模型。
7. 拓展页增加只读“琴弦超时 000”。它计数采样时刻仍有物理单元在忙的情况，饱和到 255，进入菜单或切换音色不会清零，复位清零。正常演奏预期保持 000；该项不参与 KEY0 编辑循环。

物理和弦的同时按键策略沿用原版：一个按键收集批次中 KEY2 优先于 KEY1，再优先于 KEY0，生成一个四音和弦。它不等同于三个和弦一次生成十二根弦；演示八路重叠应先后拨动。32 DDS 复音仍支持同批三键生成九个音符。

## 实现

- `physical_string_bank.v`：八个独立 `physical_string_voice` 实例；顺序扫描仅负责分配音符，八条反馈链并行计算。空闲优先，满载时已松键优先、同类按电平比较；避开正在接收新音、重填存储的声部。
- `physical_string_voice.v`：复用 512×16 延迟存储、分数延迟调音和反馈损耗；增加忙/可接收状态、电平估计和静音回收。启动保护后连续 2047 个样本幅度不超过 8 PCM 才启动淡出回收，避免零交叉误判；原 5 秒尾音上限保留。阻尼乘积向零截断，减少定点微小残留。
- 八路混音改为三级寄存加法树、固定半增益和最终饱和保护。给两组四音和弦叠加留出余量，单独一组和弦比旧四弦版低约 6 dB；不会根据活动数改变增益。
- `polyphony_bank_32.v`：空位仍优先。满载时优先已释放声部，同类选择最小包络；保留旧频率直到最多 16 个采样淡出结束，再在零幅度时更新音高并起音。正在替换的槽位不会再次分配。
- `av_top.v` / `lcd_test_pattern.v`：复用声部计数字段，琴弦显示 `00/08`，32 复音显示 `00/32`。状态包从 36 位扩展到 44 位，新增高 8 位为琴弦超时数，低 36 位布局不变；握手 CDC、帧边界提交和同步字库流水线保持原机制。

事件收集仍针对消抖后的三个板载按键，不是高速 MIDI FIFO。音符到声音的整机延迟仍包含原消抖/按键收集时间；不能把单个计算单元的周期数当成整机延迟。
