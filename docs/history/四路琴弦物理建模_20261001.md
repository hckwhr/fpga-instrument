# 四路并行琴弦物理建模

## 本轮范围

基于已上板的 `bright_all_audio_20261001`，新增四路独立的 Karplus–Strong 数字波导琴弦。每条弦拥有自己的 512×16 位延迟存储、读写指针、分数延迟调音、低通损耗、幅度损耗和触发状态。四路在每个采样时隙同时更新；没有把一条琴弦的反馈运算轮流复用成四路。

这属于简化的拨弦物理模型，不是真实吉他采样，也未包含完整琴体共鸣、弦间耦合或非线性琴桥。当前为 **4 路物理琴弦**，不能称为 32 路物理建模。已有 32 路 DDS 复音和 32 路加法分量继续作为独立音源保留。

硬件仍为 Tang Mega 138K（SOM 30354 + Dock 31005）、GW5AST-138C / GW5AST-LV138PG484AC1/I0。主时钟、音频/LCD PLL、引脚、约束及 DAC 接线均未改变，使用 Gowin V1.9.12.03。

## 上板操作

1. 按 S2 进入设置，移到“音色”，选择新增的“琴弦”（顺序为三角、方波、锯齿、琴音、琴弦）。从琴音向后按一次 KEY2 即可选择琴弦。
2. 首次试听选择“效果：原”，退出设置后演奏。原来的延时、合唱仍可用于琴弦。
3. “键法：和弦”下，KEY0/1/2 分别拨动 I/IV/V 四弦和弦，第四弦为较轻的高八度根音。
4. “键法：旋律”下，三个键分别控制根音、上行二度、三度；三个键同时触发时增加高八度第四弦。当前开发板仍只有三个演奏键，不能据此声称有四个独立外部按键。
5. “模式：拨弦”保留自然尾音；“模式：触动”在按下时拨弦，松开后施加更强阻尼。触动琴弦不会像持续激励的风琴一样无限保持音量。
6. 比较不同力度、低/中/高八度、重复拨弦与四弦同时发声。LCD 主页面和设置页均显示“琴弦”。

选中琴弦时自动停止 32 路测试；在拓展测试栏启动 32 合音/32 复音时返回普通 DDS 音色。测试音源不会被错误标为物理琴弦。

## 实现与接口

- `rtl/physical_string_voice.v`：只在拨弦时向 RAM 写入三角形弦位移与少量伪随机激励；之后完全由闭环递推生成声音。激励不是预录 PCM，持续发声也不靠重复播放初始化波形。
- 反馈链为整数延迟 → 7/8 当前值与 1/8 前值的损耗低通 → 一阶全通分数延迟 → 衰减增益 → 延迟存储。全通系数补偿低通的相位延迟。
- `rtl/string_tuning.vh` / `tools/generate_string_tuning.py`：按标称 48 kHz 生成 C3–B7 的 60 个调音参数，包含延迟长度、全通系数、损耗和初始弦位移步进。
- `rtl/physical_string_bank.v`：四个独立实例、现有键法映射、宽位数求和与最终饱和保护。第四弦的激励力度减半。
- 单弦初始化用 512 个音频时钟，反馈更新用 8 个时钟，均小于实际每采样 1024 个时钟预算。再次拨弦先用 32 个采样淡出，再初始化和淡入；尾音设置 5 秒终止上限并淡出到精确零。
- `instrument_control.v` 增加 `string_mode`，保留现有两位 DDS 音色编号；`av_top.v` 在音效器前选择物理琴弦输出。
- LCD 状态包在最高位追加琴弦标记，34 位扩展为 35 位，原有字段偏移不变。继续使用握手跨时钟域和帧边界显示提交；复用已有“琴”“弦”字形。

## 验证

六组 ModelSim 回归覆盖现有混音/菜单、32 复音、LCD 流水线、LCD 字形/计数、全音色清亮版和新增物理琴弦。新增验证检查启动静音、四路激活、触发时延、重复拨弦、源关闭、尾音归零、全部 60 个调音参数以及最大力度下各根音/音区的四弦混音。

实际生产 RTL 输出的数字音频测量（标称 48 kHz）：

| 项目 | 结果 |
|---|---:|
| 60 个音高的最大频谱估计偏差 | 0.084 音分 |
| 力度 48/96 的 RMS 比值 | 0.4987 |
| 0.1 秒松键，0.2–0.3 秒窗口相对自然拨弦的 RMS 比值 | 0.0178 |
| C4 单弦 1.0–1.1 秒窗口相对 0.02–0.12 秒的衰减 | -32.66 dB |
| 力度 96 的单弦/四弦 C 和弦峰值 | 6317 / 19326 PCM |

音准数值来自有限窗 FFT 插值估计，不是实板音准标定。触发检查测得两次采样调度后单弦出现非零输出；整机仍有约 5 ms 消抖和 2 ms 组合键收集，不将模型内部延迟冒充整机 ≤5 ms 的验收结论。

可复现命令：`./sim/run_dynamic_regression.ps1`，然后 `python tools/analyze_physical_strings.py`。数字试听在交付包 `artifacts/string_preview/`，包括单弦、四弦和弦、松键制音和跨八度音阶。
