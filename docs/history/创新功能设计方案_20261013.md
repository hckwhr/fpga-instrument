# 电子乐器创新功能设计方案（2026-10-13）

本方案建立在现有 FPGA 实时音频、原 800×480 RGB LCD、FSR0、音色切换、32 声部、八条物理弦、曲谱播放器和音效链上。HDMI、GT911 触摸和双屏方案已退出；这些功能不属于赛题二的必需项。

## 设计目标

作品的创新重点放在“演奏动作被理解、声音由并行模型产生、系统能帮助练习”三件事上。所有声音仍由 FPGA 根据实时事件逐样本合成，演奏事件记录也只保存音符/力度/时间/表情，不保存 PCM 音频。

## 功能一：压力动作识别

FSR 不只输出一个力度值，同时提取按压速度、峰值、保持时间、二次加压和释放速度。状态机将动作分为轻触、快速敲击、持续按压、重音和制音等类别。

| 输入特征 | 动作 | 声音映射 |
|---|---|---|
| 上升沿陡、峰值中等 | 快速敲击 | 短起音、较快包络 |
| 上升沿缓、保持稳定 | 连续按压 | 力度随压力渐变 |
| 已按住后再次上升 | 重音 | 临时增益或音色亮度提升 |
| 快速释放 | 制音 | 缩短释放尾音 |
| 缓慢释放 | 自然离键 | 保留当前衰减 |

实现入口是 `fsr_performance_input.v` 与 `performance_controls.v`。特征提取在采样/控制域完成，经稳定事件束送入 audio_clk；音频域只在采样边界提交动作，避免组合信号直接进入音源关键路径。LCD 显示当前动作类别和压力曲线。第一阶段只加入动作分类和显示，第二阶段再绑定音色参数。

验收：轻/中/重、快按/慢按、二次加压和快慢释放各 20 次；统计误识别、重复触发和从动作到音频的延迟。不同人的压力范围必须经过上电校准，不能使用一个固定 ADC 阈值覆盖所有人。

## 功能二：虚拟琴弦共鸣

在现有 `physical_string_bank.v` 的八条独立反馈弦之外增加受控耦合矩阵。第一版只允许相邻两弦交换一个低增益共鸣量，且每个采样边界才更新；不把八条弦直接全连接。

```text
弦 i 当前能量 -> 耦合增益/音高邻近权重 -> 弦 i+1 激励微量输入
```

参数包括共鸣开关、耦合强度、阻尼和制音。耦合增益必须限幅，反馈环路必须有单独的削顶保护和能量监视器。先做双弦仿真，再扩展到八弦；若出现超期、发散或时序下降，回退到独立弦模型。

验收：相同输入下比较独立模式与耦合模式的频谱、RMS 衰减和最大幅度；长音 30 秒不得发散或削顶；八弦满载 deadline miss 必须为零。

## 功能三：自适应练习指导

曲谱播放器已有目标音符、时间轴和速度设置。新增练习评估器，比较目标事件与实际键/FSR 事件，计算早/晚、错音、漏音、力度偏差和连续正确数。LCD 在帧边界提交结果，避免半帧状态。

- 练习模式：跟随目标音符，显示下一键和力度范围。
- 错误循环：自动重复最近错误的小节，速度从低档开始。
- 自适应速度：连续正确达到阈值后升档，连续错误降档。
- 结果页：正确率、节奏平均误差、力度稳定度和最常错音。

评估只针对 FPGA 实际收到的离散演奏事件；没有外部麦克风时，不宣称能够评价外部乐器的声学音准。验收使用固定曲谱和可控事件注入，随后再做真实按键测试。

## 功能四：演奏事件循环与重配器

记录环保存有限数量的 `note_on/note_off、note、force、timestamp、bend、vibrato` 事件。回放时事件重新进入现有音符分配器、包络和音效链，因此可以在不重新录音的情况下切换音色、速度和效果。

状态机必须处理容量、事件序号、Note On/Off 配对、循环边界、停止清空和声部抢占。回放数据不经过音频旁路，必须与正常演奏共用生产 PCM 路径。LCD 显示录制、回放和叠加层状态。

## 实施顺序

1. 先完成压力链路延迟测量和动作特征采集，不改变音色与并发结构。
2. 在独立候选中加入压力动作识别，完成仿真、综合和时序检查。
3. 实现练习评估器，先使用已有曲谱和虚拟事件，再接真实按键。
4. 实现事件循环与重配器，补充容量和异常恢复测试。
5. 最后评估双弦共鸣；它最容易影响 audio_clk 时序和反馈稳定性。

每一项都必须保留回归、资源、P&R、时序、引脚和实物证据；创新功能不替代基础要求的延迟、复音和实时发声验收。
