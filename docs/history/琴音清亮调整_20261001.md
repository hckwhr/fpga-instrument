# 琴音清亮调整

基线：用户已确认上一版声音更细腻，但偏闷。本轮仍为 GW5AST-138C / GW5AST-LV138PG484AC1/I0，SOM 30354 + Dock 31005，不改变硬件接口、时钟约束、按键或菜单。

## 改动

仅修改两个合成源文件：`rtl/audio_voice_mixer.v` 和共用的 `rtl/piano_wave.vh`。

- 普通琴音低通系数从 1/8 改为 1/2，48 kHz 采样下的 -3 dB 频率约从 1.02 kHz 移到 5.52 kHz，减少中高频被压低造成的闷感。三角波、方波、锯齿波仍使用原滤波。
- 琴音从 `6900 × [sin(p)+0.20sin(2p)+0.06sin(3p)]` 调整为 `6500 × [sin(p)+0.28sin(2p)+0.12sin(3p)+0.04sin(4p)]`。增加二至四次谐波，同时降低基音比例系数来保持近似响度和混音余量。普通琴音和 32 复音共享此波形。
- 查表从 64 点增至 128 点，保留 8 位线性插值，避免谐波增加后插值精度下降。
- 上一轮的细腻起音、12 位动态包络、尾音和连续相位换音全部保留；32 复音原本没有普通演奏的重低通，本轮只受共用音色变化影响。

## 仿真与对比

五组回归通过。额外逐采样比较三种基础波形，各 4096 个采样与上一版完全一致。遍历新琴音全部 32768 个插值相位，最大插值误差为 6.887 PCM 单位，小于独立公式推导的 12 单位误差界；默认动态包络仍为 192 个采样起音、792 次渐弱、尾音 1.538 秒。

该片段 1 kHz 以上相对功率增加约 8.75 dB，RMS 增加约 0.28 dB。这些数字描述上述测试片段，不是模拟扬声器测量，也不保证每个音符都有相同幅度的变化。

`artifacts/audio_preview/equal_rms_before_then_after.wav` 是等响度 A/B：先播放上一版，再静音半秒，随后播放本轮版本。对比基线已经更新为上一版琴音，而非最早的三角波。试听文件由 RTL 仿真输出转换，属于数字预览。

复现：英文路径工程根运行 `./sim/run_dynamic_regression.ps1`，再运行 `python tools/render_smooth_audio.py`。

## 上板听什么

默认“琴音＋拨弦＋和弦＋效果原”，分别按三个键，听单音/和弦是否更清楚、尾音是否仍然细腻；再试高八度和 32 复音叠加，留意是否过亮或刺耳。此前三个基础波形的声音应保持一致。

本轮未烧录，上一版可回退文件仍在 `artifacts/smooth_audio_20261001`。上次永久 Flash 烧录用 USB Debugger A（当次扫描 cable-index 4）、显式 `--frequency 0.5MHz`、操作 69 成功；操作 1 重新加载也成功。后续下载重新扫描确认设备，不把历史 cable-index 当成固定编号。
