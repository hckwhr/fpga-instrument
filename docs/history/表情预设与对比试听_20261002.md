# 表情预设与对比试听

## 自审结论

上一版算法仿真证明了频率变化，但演示体验没有跟上功能数量：需要先确认普通DDS、触动方式、合适的音色和音效，再换键辨认滑音或长按辨认颤音。琴弦、32路通路不使用这两个参数，反复按同一键也不一定出现明显滑音。用户“听不出来”不能用“仿真通过”直接否定；当前没有新的板上录音，因此不能断言扬声器端效果已经足够明显。

本轮收敛表情操作，并加入同旋律、同电平的连续A/B对比。保留基础／拓展两页和题目所需的已有能力，不再增加独立的滑音速度、颤音强度组合。

## 操作

1. S2 打开设置，KEY2 选择拓展页；KEY0 选择“表情预设”。KEY1／KEY2 在“原声、滑音、颤音”之间切换。
2. 选择预设会同时设置：触动、三角波、单音映射、C根音、中八度、手动力度96、原声音效，停止32路源并关闭物理琴弦。LCD 底部明确显示预设组成。它会修改这些基础设置，退出后不会恢复之前的音色。
3. KEY0 移到“对比试听”，KEY2 准备，S2 开始。若原来选的是原声，准备试听会自动选择滑音作为比较对象。
4. 无需按演奏键，自动循环：A原声四秒→B滑音或颤音四秒。同为C→G→C，包含起音、持续、释放和尾部静音。LCD 显示“对比试听 A：原声”或“B：滑音／颤音”。
5. S2 停止试听并返回设置，再按S2回演奏页。保留表情预设，可用KEY0／1／2手动演奏。预设仍允许之后从基础页修改音色、根音等。
6. 回到表情预设选择“原声”即可取消滑音和颤音。琴弦、32合音和32复音仍按原方式操作，表情预设只作用于普通四声部DDS。

## 应听到的区别

- 滑音：A段C→G直接换音，B段用约341毫秒逐渐升到G，再逐渐回到C；首音不从零频率起滑。
- 颤音：A段持续音平稳，B段每秒约5次音高起伏，尤其最后持续的C音容易比较。
- 两段使用相同音色、包络和力度。没有用增大B段音量代替音高效果。当前选取的慢滑音、强颤音用于辨认；尚未宣称它们是最自然的乐器演奏参数。

## 实现

- `instrument_control.v` 统一应用完整预设、准备／停止试听，S2优先，测试源互斥。
- `expression_audition.v` 仅产生采样时钟驱动的C-G-C音符和A/B阶段，不生成另一套PCM。实际声音仍经过普通 `audio_voice_mixer`、原效果旁路和PT8211链。
- 各四秒段末先释放包络，最后250毫秒在静音中清除音高历史和相位，下一段从一致状态开始。
- `audio_voice_mixer.v` 在音符查表后增加一级频率字寄存，拆开原来余量仅0.019ns的音高组合计算链。表情关闭时直接使用原频率字，保留PCM逐样本兼容。
- LCD状态握手从48位扩为51位，高三位依次为试听准备、运行、B段；仍在帧边界提交。钢琴键表示当前目标音名，波形来自实际输出采样。日常主界面用当前表情替换原“32停止”提示，并保留音效标识；32路和琴弦的实际运行计数不受影响。
- 未改引脚、PLL、外部总线或现有传感器方案。

## 自审边界

本轮主要完成可操作性、可比较性与显示一致性，没有声称开发板声音已经达到真实乐器的质感。普通手动演奏仍可选择其他音色；实体琴弦与32路通路暂不受表情参数控制。试听使用三角波以便辨认音高，峰值较四声部和弦低，这是单声部对比的实际电平，用户可以使用功放音量旋钮调整整体响度。

代码审查以已烧录的 `expression_20261001` 为基线，检查了源互斥、预设状态、退出清理、采样边界、流水级稳定时间、数字音量、菜单优先级、状态CDC及字体容量。两路对比共用实际DDS，没有旁路替代算法。保留上一版源文件及镜像，正式同步前检查哈希并备份。
