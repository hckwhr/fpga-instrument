# C17 灯带（12颗）与 S3 拓展四联调

候选源码：`work/v3_rgb12_stage61_20261020`。基于已验收、已烧录的 stage59b 独立复制；不覆盖旧版。

## 接线

沿用现有 WS2812B 单线 GRB 协议。若实物是四线共阳/共阴 RGB 灯带，则不能使用此单线驱动，须先核对型号。

| 信号来源 | 连接目标 |
|---|---|
| FPGA C17，`ws2812_data` | 灯带第一颗的 DIN（箭头输入端） |
| 灯带电源 | 按灯带标注接电源，不能用 C17 供电 |
| 灯带 GND | FPGA GND |
| S3 GPIO17 / TX | FPGA A20 / RX（J13-15） |
| S3 GPIO18 / RX | FPGA A21 / TX（J13-17） |
| S3 GND | FPGA GND |

UART：3.3V TTL、9600 baud、8N1、无流控。需要两根信号线及公共地。A15 是 ADC 时钟，不作 UART。
FPGA 的 CST 本来就把灯带数据绑定在 C17；本轮改的是发送长度 36→12，不迁移其他引脚。

S3 继续使用已烧录的 BLE 桥接固件，设备名“行者无疆”。源码 `firmware/esp32s3-bridge/main/board.h` 已确认 GPIO17/18 与 9600 配置。

## 灯带测试与正常行为

新候选完整版本上电先发送全黑帧，然后全红、全绿、全蓝，各约 0.25 秒，之后白灯从第1颗依次走到第12颗；总自检约3.74秒。自检只接管灯带，音乐、菜单与 UART 沿用完整版本。复位会重新自检。
结束后恢复原按键/曲谱提示，12位音级掩码一位对应一颗灯，不再一位重复三颗。
原设计的曲谱提示按 C、C#、D、D#、E、F、F#、G、G#、A、A#、B 折叠音级；钢琴白键跨八度模式与实体键位的一一教学映射不在本轮改变范围内。先用“同音色”半音键盘模式核对位置。

模块默认仍保留旧版36颗配置，既有测试不减少；硬件顶层显式选择12颗及开机自检。
新增两项数据引脚解码仿真，验证每帧恰好288位、GRB/MSB、位宽/周期、锁存低电平、12个位置、帧原子更新、RGB自检结束后恢复实时输入及复位。

## 拓展四实测顺序

1. 接好 UART 与公共地后，启动桌面 FPGAvedio，进入 FPGA 模式，扫描 BLE 并连接“行者无疆”。
2. 先识别设备，必须收到 FPGA 返回的 CAPS，才能判定 S3↔FPGA 双向串口通。
3. 先导入现成 MIDI：`host/instrument-web/test/fixtures/fpga-scores/twinkle.mid`，转成 FPGA 曲谱并上传。收到 COMMIT ACK 才算上传成功。
4. 发送播放，检查 FPGA 发声、LCD 进度、灯带提示与暂停/停止。BLE 显示已连接不代表曲谱已经上传或播放。
5. RAM 上传曲谱断电后丢失，内置 ROM 曲目仍保留。

以上是接线和验收操作，不冒充已经看到灯带发光或已经完成实物 BLE→FPGA 播放；最终构建、烧录和实际观察结果另记 artifacts。
