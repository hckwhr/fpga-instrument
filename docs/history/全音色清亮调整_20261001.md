# 全音色清亮调整

## 范围和原因

用户反馈：不只是琴音，三角波、方波和锯齿波也发闷。上一轮 `bright_audio_20261001` 只放宽了琴音滤波，三种基础音色仍为 `FILTER_SHIFT=3`，即 48 kHz 采样下约 1.02 kHz 的一阶低通。它压低了决定音色清晰度的中高频泛音。

本轮基于该清亮琴音版本，把 `rtl/audio_voice_mixer.v` 的基础音色默认 `FILTER_SHIFT` 从 3 改为 1。四种普通演奏音色现在均使用约 5.52 kHz 的一阶低通；琴音的上一轮泛音、128 点插值表保持不变。基础波形发生器、音阶、力度、ADSR/拨弦包络及混音增益均保持原值。波形间的性格区别仍在：三角波谐波天然较少，方波与锯齿波更明亮。

沿用 Tang Mega 138K（SOM 30354 + Dock 31005）、GW5AST-138C / GW5AST-LV138PG484AC1/I0、Gowin V1.9.12.03。顶层 `av_top`、50 MHz 主时钟、音频/LCD PLL、复位、引脚和约束均未修改。

已追踪生产链路：普通演奏混音/滤波 → 音源选择 → 原声/延时/合唱 → PT8211 串行输出。32 复音和 32 合音走独立音源，原本就不经过此次修改的普通演奏低通。本轮不把它们标记为获得了同样的滤波提升。

## 仿真证据

`sim/run_dynamic_regression.ps1` 的五组回归全部通过，ModelSim 编译及各组仿真均为 0 错误、0 警告。

- 三种基础音色分别输出 144000 个采样的 I–IV–V–I 拨弦乐句；逐采样核对滤波前的 `raw_sample` 与旧版一致，确认音高、波形和包络未被改写。
- 在最大力度下遍历四种音色、三个八度、12 个根音以及两种包络，共 288 组四音和弦。测试包含 V 和弦的升高根音，每组 2048 个采样。滤波前混音没有触发饱和，干声输出峰值 28544，未到达 16 位削顶值。
- 各音色拨弦乐句结束后回到精确零值；琴音插值最大误差仍为 6.887 PCM；动态声部包络仍为 192 个采样起音、792 次渐弱变化，单音尾部最终归零。
- 普通和弦/旋律、ADSR、动态 32 声部分配/替换、LCD 波形/电平与实时计数回归通过。
