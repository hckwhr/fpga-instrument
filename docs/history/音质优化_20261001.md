# 音质优化：柔和琴音与精细包络

本轮基于用户已实测通过的动态 32 复音版本。目标板仍为 SOM 30354 + Dock 31005，GW5AST-138C / GW5AST-LV138PG484AC1/I0；时钟、引脚、PT8211 输出及设置操作沿用已有设计。

## 原因与改动

旧 32 复音使用 4 位增益，默认力度只有 12 次主要衰减，间隔约 125 毫秒，最后一级仍有明显幅度。音源只有三角、方、锯齿三种基础波形；这些音色有意保留其谐波特征，不能直接当作柔和乐器音色。旧普通触动释放在默认持续音量下只有约 6 毫秒，起音也偏短。

- 新增第四种“琴音”，并设为开机默认。公式为 `6900 × [sin(p) + 0.20 sin(2p) + 0.06 sin(3p)]`，采用周期表和线性插值，以基音为主、保留少量谐波。普通演奏及 32 复音共用同一个波形函数。它是合成键盘音色，不是真实钢琴采样或钢琴物理建模。
- 三角波、方波、锯齿波全部保留。音色设置共四项，按 KEY1/KEY2 循环选择；中文新增“琴”字并正确扩展字库地址位宽。
- 32 路包络由 4 位升级到 12 位，每采样柔和起音，尾音以较细的近似指数曲线下降到零。默认力度 96 的起音为 192 个采样，约 4 毫秒；实测仿真尾音约 1.538 秒，792 次衰减更新。
- 满载替换旧声部时保留相位和当前音量，避免强行归零造成的波形突变。依旧先用空闲声部，再循环替换；这不是完整的双声部交叉淡化，极端音高切换仍须实听。
- 普通演奏默认起音由增益步进 4 改为 1；触动释放由每 2 个采样下降一级改为每 48 个采样下降一级，默认持续音量下释放约 144 毫秒。普通演奏原有 ADSR 结构保留。
- 保留固定混音余量，不通过随声部数变化的归一化拉扯音量，也没有增加混响来掩盖音源问题。

## 验证与试听

在英文路径工程根目录执行 `./sim/run_dynamic_regression.ps1`，运行五组测试；随后执行 `python tools/render_smooth_audio.py` 生成试听文件。

测试覆盖原有按键、I/IV/V 和弦、旋律、设置、LCD、满 32 路分配、独立释放，以及新增的四音色循环、中文“琴音”显示、抢占时相位连续性、12 位起音与尾音、逐采样混音参考值。

`tb_smooth_audio` 用独立三角函数公式验证整周期的 16,384 个相位点。最大插值误差为 16.598 PCM 单位，在由二阶导数、表值舍入和插值量化推导的 22 单位误差界内。

以下为 RTL 仿真产生的同一段 I–IV–V–I 音频，不是扬声器录音：

| 指标 | 修改前默认三角波 | 修改后默认琴音 |
|---|---:|---:|
| 整段 PCM 峰值 | 17611 | 16596 |
| 第一和弦稳定段 RMS | 4430.865 | 4773.314 |
| 稳定段 5 kHz 以上能量占比 | -57.902 dB | -81.857 dB |
| 削顶采样数 | 0 | 0 |

5 kHz 以上占比下降约 24 dB，仅说明这一段音频的高频成分减少，不代表模拟输出信噪比或所有音符的音质指标。新琴音保留的二、三次谐波与旧三角波不同，最终悦耳程度需上板试听。

`artifacts/audio_preview` 下的 `before_triangle.wav`、`after_keyboard.wav` 是未归一化的原始数字输出；`equal_rms_before_then_after.wav` 将新音色按第一和弦 RMS 匹配到旧音色，先旧后新，中间静音半秒，避免用响度差误判音质。`polyphony_keyboard_tail.wav` 是 32 路引擎中单声部的尾音，因固定预留 32 路混音空间而较轻。

## 上板验证

1. 普通演奏，“琴音＋拨弦＋和弦＋效果原”，按 KEY0/1/2 比较起音、音色和尾音；再与三角波对比。
2. 改成触动，按住后松开，应有短暂自然释放，不应像开关一样硬切断。
3. 进入 32 复音运行，连续敲击，再停止；观察尾音平滑结束、计数最终回到 00/32。
4. 达到 32/32 后继续换键，留意换音是否有明显爆音。
