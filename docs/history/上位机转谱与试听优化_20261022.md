# 上位机转谱与试听优化 · 2026-10-22

已更新桌面 `C:/Users/hck/Desktop/FPGAvedio`，重新启动程序生效。本轮没有烧录 ESP32 或 FPGA。

## 修改

- 重叠同音默认保留独立敲击，避免混响尾音导致重复旋律被合并；仍提供显式的旧合并模式。
- 同时起音分组只选择旋律声部，不再把旋律提前到伴奏的起音时刻。
- 优先整段移八度到板端音域，保留跨 B5/C6 等边界的旋律走向；超出整个三八度范围时，报告仍需逐音折回的数量。可选择旧逐音折回方式。
- 手动 BPM 量化支持拍点偏移，不再必须把选段开头当作拍点。默认仍保留原始节奏。
- 新增“试听待上传曲谱”，读取同一个上传编译结果，以实际 6.25 ms tick、音高和力度试听，无需 BLE；改变速度、力度或旋律轨时停止旧试听。
- 试听调度跳过后台停顿期间已经结束的音符，正在持续的音符保持原结束时间，避免迟到音符集中重放。
- 新增整理参数随曲谱存档保存；旧 v1 存档仍可读取。
