# V3 实际引脚与程序适配（2026-10-15）

依据：`硬件/V3/原理图.pdf`（导出时间 2026-10-15 20:01）、同目录 `A15-CS0(2).txt`。
用户确认摇杆已焊接。仅收到原理图和配对文本，尚无 PCB 网表或通断实测，因此本记录证明原理图/约束对应，不证明焊接连续性。

FPGA：Tang Mega 138K，SOM30354 + Dock31005，GW5AST-138C，PG484A；50 MHz V22，Bank2=3.3 V。
沿用 stage38 已确认的转接板插法：U6 奇数脚 n 对应 Dock J13 的 n+11，偶数脚 n 对应 J13 的 n+9。
本次五个 SPI 配对锚点与此关系全部吻合。厂家 Dock 图第19页、球位图第7页作为底板依据。

CESHI 脉冲宽约20.345 ns。示波器捕获需足够采样率；它标记数字事件被音源接受，不能替代 FSR 模拟电压作为物理输入起点。
多键同时按下会依次产生事件脉冲。主音频仍走底板 PT8211，LCD 仍走原 RGB 排线接口，未恢复 HDMI 或触摸。

## 模拟输入

| 器件通道 | 实际信号 | 程序功能 |
|---|---|---|
| U1 CH0..7 | FSR0..7 | 十二音级中的0..7，独立触发/力度 |
| U2 CH0..3 | FSR8..11 | 十二音级中的8..11，独立触发/力度 |
| U2 CH4 | URY | 摇杆Y → 颤音深度 |
| U2 CH5 | URX | 摇杆X → 弯音 |
| U2 CH6 | OUT1 | 旋钮 → 实体键力度比例（约1/8..1） |
| U2 CH7 | ANJIAN | 原理图中未连接，扫描但不参与按键/校准 |

摇杆连接器：1=GND，2=3.3V，3=URY，4=URX，5=NC。已焊好的 X/Y 两轴正常支持；“按下摇杆”开关在本图中没有接通，不能作为独立按键使用。

两颗 ADC 共享 SPI，独立片选；SPI mode0、1MHz、片选高间隔至少1μs。完整16通道帧约0.524ms。
Stage54 改为逐通道独立校准：上电压力键松开、摇杆居中，每个通道先等8帧，再取32帧稳定平均，分别计算12个零点及X/Y中心。
校准允许 FSR 原始值≤128，X/Y为256..768且连续稳定。按住、未接或噪声过大的通道只暂缓自身校准，其余压力键仍可用；恢复松开稳定后自动补校准。尚未校准的摇杆轴输出中性值。
每键相对自身零点：连续两帧≥24触发，连续两帧≤12释放；力值约为压差/2，压差≥254达到127，再乘旋钮比例。
该阈值是初始软件值，需实物测量后调整。声部的持续力度按各自音级索引，按重一键不会提高其他键的包络目标。

输入帧通过原有稳定数据握手整体跨入音频域；5ms无新帧会撤销就绪并释放实体键。菜单/超时恢复后，已按住的键必须先松开才能重新触发。
当前12键事件接入32声部DDS实时模式；物理弦模式仍沿用原板载按键路径，本次未增加实体12键物理弦事件分配。
实体键不包含旧提案的4个74HC165菜单键，菜单仍使用原板载按键。
PMOD官方四灯低有效，bit3=已有压力通道校准且持续收到帧、bit2=任意压力键按下、bit1=最大力度≥64、bit0=最大力度≥32。bit3不表示所有通道均已校准，也不能单独证明SPI物理连通。

## ESP32-S3

固件 `firmware/esp32s3-bridge` 已改为 UART1 TX=GPIO17、RX=GPIO18，9600 8N1。
GPIO39（模组32脚）为 ESP_PA_CTL，经R51接MAX98357A SD_MODE；本桥接固件置低关闭语音功放。
低电平关闭依据 MAX98357A 手册第17页 Table5；不再沿用旧提案的GPIO18高有效MOS静音。
保留USB GPIO19/20，不初始化PSRAM或语音I2S。旧stage48二进制对应旧引脚，不能直接用于本V3。

## 电路边界

RGB连接器1=GND、2=RGBIO、3=3.3V、4=5V；本原理图未见旧提案的AHCT电平缓冲器或LED_ENABLE。
程序只输出3.3V数据；不能据此保证5V灯带的高电平阈值合格，需按实际灯型号验证。
5V供电网络在原理图中共网，不应把图上未画出的电源隔离当成已实现。
