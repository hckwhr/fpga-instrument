## 用户确定的接线方案

- 显示：FPGA 板正面的 HDMI 接口通过 HDMI 线连接屏幕 HDMI 驱动板，再由驱动板驱动屏幕。
- 触摸：屏幕 GT911 触摸排线接 FPGA 板背面的触摸排线接口，通过独立 I²C 链路读取触摸信息。
- HDMI 承担画面传输；本方案的触摸坐标通过背面排线回传，不通过 HDMI 传输。

这是用户明确的目标接法；本记录初建时未按 Dock 31005 原理图逐针验证背面接口，
也未确认排线两端接触方向及供电，不将目标接法表述为已实测兼容。

## 尚待确认

- HDMI 驱动板支持的输入时序/EDID；面板与驱动板型号已由 2026-10-12 厂家文件补充，但面板 TTL 时序不等于 HDMI 输入模式表。
- 实际套装的供电和背光配置；厂家文档存在最低输入电压、LED 数量及电流的矛盾，详见下方核对记录。
- GT911 寄存器手册、屏厂配置、复位/INT 地址选择时序、坐标范围和方向。
- FPGA 板端连接器针序、接触方向及电气核对。卖家的“可以”不等于已经完成针脚逐一核对或上板测试。

## 后续开发重点

先核对板端 HDMI 与背面触摸接口，完成 1024×600 显示适配和 GT911 初始化、坐标读取，
再接入现有菜单与参数操作。显示适配包含 HDMI 输出链路、像素时序及界面布局调整；
不能只把现有 800×480 RGB LCD 的分辨率常量改掉就视为完成。
验证触摸按下、移动、抬起、边界坐标和连续操作，以及画面更新、触摸通信与实时音频并发时的稳定性。
具体交互功能在硬件接口明确后细化；当前记录不表示驱动已实现或屏幕已实测。

这款触摸屏应作为独立的后续开发项，不能继续以早期“官方7寸800×480 RGB裸屏”的规格代替。

## 2026-10-11 板端核对与开发进度

板卡已锁定 SOM30354 + Dock31005、GW5AST-138C PG484A。下表是 FPGA 封装球号，
不按接口外观推算。依据本机原理图 SOM 连接页与官方 PG484A HDMI colorbar CST：

| 信号 | FPGA 球号 | stage41 用途 |
|---|---|---|
| HDMI D0 P/N | J14 / H14 | TMDS 蓝色与同步控制 |
| HDMI D1 P/N | J15 / H15 | TMDS 绿色 |
| HDMI D2 P/N | K17 / J17 | TMDS 红色 |
| HDMI CLK P/N | G15 / G16 | 转发像素时钟 |
| DVI-A_ALT / DVI_DIR_SEL | K14 | 固定高电平，选择 TX |
| DDC SCL / SDA | M13 / L13 | 本阶段未驱动，后续可读 EDID |
| HDMI HPD | K13 | 本阶段未接入逻辑 |
| J6 RST / INT / SDA / SCL | T15 / T16 / U16 / W16 | stage35 已实现 GT911 读取 |

J6 针序为 1 RST、2 3.3V、3 GND、4 INT、5 SDA、6 SCL，板上 SDA/SCL 各有
5.1kΩ 上拉。HDMI 使用官方例程的 LVCMOS33D、8mA 与 ELVDS_OBUF 配合；
不能把旧 HDMI 子页上另一封装的球号直接抄入当前 CST，尤其方向脚是 K14 而非 T14。
方向控制高电平使能板上 +5VD，并选择 TX 端接。屏幕/驱动板电源仍按卖家规格独立提供。

stage41 在已实测通过的 stage40 上加入独立 HDMI 测试图；83 项回归与厂商串行器
