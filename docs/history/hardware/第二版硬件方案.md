## 1. 结论

第二版不推翻第一版的 12 键架构：

```text
12 键按键板 -> 2 x 74HC165 -> FPGA -> 音符/和弦选择
FSR402 -> 电阻分压/滤波 -> MCP3008 -> SPI -> FPGA -> 拨弦/力度
FPGA -> PT8211/板载音频 -> 音响
FPGA -> RGB666 LCD -> 状态显示
```

采用一个全局 FSR402，不做 12 路逐键压力传感器。按键负责选择音高和和弦，FSR 的一次快速压力变化负责拨弦触发，压力峰值负责力度。多个按键同时按下时，在同一个拨弦事件上锁存按键位图，使多个声部同时起音。

## 2. 第一版保留与必须优化项

### 2.1 保留项

- 两片 `74HC165` 级联方式保留。
- 12 个独立按键保留，不改成矩阵键盘。
- `U1 Q7 -> U2 DS -> KEY_SERIAL_DATA` 级联关系保留。
- `KEY_LOAD_N`、`KEY_SHIFT_CLK`、`KEY_SERIAL_DATA` 继续作为三根按键接口信号。
- 第一版已验证的按键板可继续用于软件和音频联调。

### 2.2 第一版必须补强

1. U1、U2 每片增加一个贴近 VCC/GND 的 `100 nF` 去耦电容。
2. 板级电源入口增加 `4.7--10 uF` 和一个 `100 nF`。
3. V2 使用全部 16 路输入：12 个音符键、3 个功能键、1 个摇杆按键，见第 12.2 节。旧版 U2 D4--D7 固定接地仅适用于未安装功能键的 12 键板；V2 不可把这些按键输入直接短接地，应与其他按键一样设置确定的硬件上下拉。
4. 确认 U1 的 DS 接确定低电平，两个器件的 CE# 均接有效电平。
5. 按键板所有逻辑器件统一使用 `3.3 V`，不得接 5 V 逻辑。
6. `CLK/LOAD/DATA` 预留 `22--47 ohm` 串联电阻，排线较长时优先装 `33 ohm`。
7. 增加 `3V3、GND、LOAD、CLK、DATA、DS2` 测试点。

按键消抖由 FPGA 完成，不能用很大的按键电容替代消抖，否则会增加多键同时按下时的延迟和边沿不确定性。

## 3. 红框与蓝框连接位置审核

### 3.1 红框位置

红框对应 Dock 的两组 PMOD 区域（官方原理图中的 J8/J9）。电气上适合接入控制板，但 LCD 安装后会遮挡上方区域，且按压控制面板时容易碰到屏幕、排线或散热结构。

结论：**不作为最终机械安装位置**。PMOD 可保留为调试和原型接口。

### 3.2 蓝框位置

官方 `E:\gaowin\硬件资料\02_Schematic\DOCK\Tang_Mega_NEO_Dock-138K_31005_Schematics.pdf` 第 19 页标明 **J13/SDRAM0（靠 PCIe）** 与 **J14/SDRAM1（靠 PMOD）**；第 7 页给出 SDRAM0 网络到 FPGA 球脚的映射。

- J13 是 2×20、2.54 mm 接口，按 Pin 1 与官方针号画板，不能按照片左右镜像。
- J13-11 为 `5V_Peripheral`，J13-12 为 GND。本方案不使用 29/30 脚的可选电阻网络取电，控制板自行产生 3.3 V。
- 本方案使用的 SDRAM0_D0..D7、D10..D15 均属于 Bank2；SOM30354 电源页 FB15 将 VCCIO2 接到 3V3。信号采用 LVCMOS33，不承受 5 V。
- J13 用作控制板后，不得同时接 SDRAM0 扩展模块或启用同脚 SDRAM0 控制器。SOM 板载 DDR3 与此接口不是同一组网络。
- 旧 J14 与 PMOD0 复用的限制不适用于此 J13 表；其他外设仍须对照实际 CST 审查。

### 3.3 对队友的最终要求

建议采用蓝框位置，但必须采用下面的方式：

1. 控制板主接口命名 `J_CTRL`，使用 KEY/ADC/LED/BT 等功能网络名。
2. J_CTRL 的接触编号与 Dock J13 一一对应；核对母座插合面与 PCB 焊接面，禁止镜像。
3. 第 4.1 节统一分配按键、ADC、LED、调试和蓝牙，不再复用旧 PMOD0 的球脚约束。
4. J13-11 的 5V_IN 进入本地 LDO及蓝牙供电选择电路；不得接到 MCP3008、74HC165 或 FPGA 信号脚。
5. J13-12 接公共地，接口旁设置 GND 测试点。未使用的 J_CTRL 接触脚保持 NC。
6. 同一 UART 只接一个模块；安装控制板蓝牙后，移除原 J13 上的 HC-05 杜邦线，禁止两个 TX 输出相连。

第二版使用完整、低矮的 `2x20` 母座与 J13 插接，避免短排母插偏一列。控制板必须增加独立支撑点，J13 只承受插拔力，不承受按键、摇杆或 FSR 的操作压力。

### 4.2 控制板供电

J13-11 提供 `5V_Peripheral`，控制板增加：

```text
5V_IN -> 输入保险/磁珠可选 -> 3.3 V LDO -> 74HC165/MCP3008/FSR 分压
                                      |
                                10 uF + 100 nF
```

目标为稳定 3.3 V，器件容差和纹波按实际 BOM 手册审查，不以 3.0--3.6 V 的宽范围代替验收。LDO 容量按控制板、LED、摇杆及可选蓝牙的峰值总电流并留余量选取，计算 `(5V-3.3V)×电流` 的热耗散。第一版 PMOD 供电和第二版本地电源不得并联。蓝牙供电通过第 13 节互斥选择，初次装配默认断开。

## 5. FSR402 + MCP3008 电路

### 5.1 FSR 分压

推荐将 FSR 放在高端、固定电阻放在低端，使压力增大时 ADC 电压增大：

```text
3V3_LOCAL
   |
 FSR402
   |
 SENSE0 ---- 1 kohm ---- MCP3008 CH0
   |                         |
 RPD=10 kohm              100 nF
   |                         |
  GND                       GND
```

- `RPD` 默认 `10 kohm`，预留 `22 kohm` 和 `47 kohm` 可替换位置。
- FSR402 本身就是变化电阻；模拟通道不需要再并一个对称的固定上拉和下拉。额外同时使用上下拉会压缩有效变化范围，先不要这样做。
- 所有数字输入的上下拉可以使用硬件电阻，见下一节。
- FSR 不是精密牛顿力传感器，力度值必须做零点和满量程校准，显示和声音控制使用归一化力度值。

### 5.2 MCP3008 电源和 SPI

- VDD 使用 `3.3 V`。
- VREF 使用 `3.3 V`，VREF 旁放 `100 nF`，芯片旁再放 `100 nF` 和 `1 uF`。
- `ADC_CS_N` 使用 `10 kohm` 硬件上拉，保证 FPGA 配置期间 MCP3008 不工作。
- `ADC_SCLK`、`ADC_MOSI` 使用 `10 kohm` 硬件下拉，防止上电期间产生伪 SPI 事务。
- `ADC_MISO` 可加 `47--100 kohm` 下拉，避免 CS 未选中时悬空。
- SPI 线上预留 `22--47 ohm` 串联电阻，默认 `33 ohm`。
- 未使用的 MCP3008 通道不要悬空，使用 `10 kohm` 下拉或引到带明确电平的测试焊盘。
- FSR 接口建议三针：`3V3_LOCAL、SENSE0、GND`。若传感器线较长，SENSE 线旁必须有地线。

### 5.3 模拟布局

- MCP3008、FSR 分压电阻和 ADC 输入电容放在控制板同一区域。
- SENSE0 走线短，远离 `KEY_SHIFT_CLK`、LCD 像素时钟、音频 BCK 和 SPI 时钟。
- 使用连续地平面，不要把模拟地拉成一条很长的细线。
- FSR 上方增加均力片或硅胶垫，避免只在传感器中心形成点压力。

## 6. 按键和模式控制

### 6.1 当前板载键定义

以 2026-10-03 当前固件为准；早期 KEY0 复位方案已不适用：

| 板载键 | FPGA 脚 | 当前定义 |
|---|---|---|
| KEY0 | `AA13` | 普通演奏/菜单键，低有效 |
| KEY1 | `AB13` | 普通板载键，低有效、内部上拉 |
| KEY2 | `Y12` | 普通板载键，低有效、内部上拉 |
| SOM S2 | `F4` | 设置页进入/退出，高有效，属于 1.5 V IO，不能外接本板 3.3 V 信号 |

现有复位由 PLL 锁定与分域复位同步产生。控制板的 MODE/PREV/NEXT/ENTER 经 74HC165 采集，不直接并接板载键。S2 继续可用于现有板演示；新板功能键由后续固件映射到菜单操作。

### 6.2 建议的运行模式

| 模式 | 按键/传感器行为 | LCD 状态框 |
|---|---|---|
| `PLAY` | 12 键选音，FSR 拨弦并控制力度，支持和弦 | `MODE: PLAY` |
| `TRIGGER` | 只验证压力越过阈值时的一次触发 | `READY/TRIGGER` |
| `FORCE` | 显示原始 ADC、滤波值和力度条 | `FORCE: xxx` |
| `PLUCK` | 固定音高，验证一次按压只触发一次 | `ATTACK/HOLD/RELEASE` |
| `NOTE` | 显示单音或当前和弦位图 | `NOTE: C4 E4 G4` |
| `TONE` | 选择钢琴、拨弦、三角波等音色 | `TONE: ...` |

`PLAY` 中所有链路同时启用；其他模式是调试/演示页面，不是把硬件链路拆成多个 bitstream。

### 6.3 LCD 显示要求

现有 RGB LCD 必须连续按行场时序扫描，不能停止整屏扫描。菜单与演奏页分开，状态快照在帧边界提交，避免同一帧使用不一致的数据。保留当前稳定显示链路，新板只补输入状态，不采用“禁止整屏刷新”的旧描述。

## 7. 拨弦检测定义

FSR 原始值经过滤波后进入以下状态机：

```text
READY
  -> 压力快速上升且超过触发阈值
ATTACK：输出一个 pluck_pulse，记录压力峰值
  -> 压力仍高于保持阈值
HOLD：禁止重复触发，力度可继续控制音量/包络
  -> 压力低于释放阈值
RELEASE
  -> READY
```

触发阈值和释放阈值必须有滞回，不能使用一个阈值反复比较。建议启动后采集空载基线，触发使用“基线 + 上升阈值”，释放使用更低的阈值。

## 8. FPGA 代码分层合同

硬件队友只需按信号合同画板，代码保持一个工程、一个永久下载 bitstream，模块分开：

```text
keypad_165.v       74HC165 扫描和消抖
note_mapper.v      12键到音符、和弦位图
mcp3008_if.v       SPI 采集和采样有效脉冲
pressure_filter.v  基线、滤波、归一化力度
pluck_detect.v     拨弦状态机和 velocity
mode_ctrl.v        KEY0/KEY1/KEY2 或功能键模式控制
tone_bank.v        音色选择
voice_manager.v    多声部同时起音、释放和回收
lcd_status.v       固定状态框和局部刷新
audio_core.v       DDS、包络、混音和 PT8211 接口
top.v              只负责连接和时钟复位
```

## 9. PCB 布局要求

1. 蓝框侧的控制接口放在 LCD 下方边缘，连接器高度低于 LCD 支撑结构。
2. FSR 和 MCP3008 放在控制板靠近传感器的一侧，数字接口放在另一侧。
3. 74HC165、MCP3008、74HC595（若第二版继续驱动指示灯）每片芯片旁放 `100 nF`。
4. 控制板增加 `1--4.7 uF` 局部储能，LDO 输入/输出按具体器件数据手册放置电容。
5. `CLK/LOAD/SPI_SCLK` 不要和 SENSE0 平行长距离走线。
6. 排线长度优先控制在 `15--20 cm`，最长不超过 `30 cm`。
7. 所有连接器标注 Pin 1、3V3、5V、GND 和信号名；不能只依靠颜色区分。
8. 控制板必须有独立机械支撑，不能让按键压力传到 Dock 排针或 LCD FPC。
9. 下单前打印 1:1 纸样，核对蓝框连接器位置、LCD、散热器、USB 口和螺柱干涉。

- [ ] 1:1 纸样和机械干涉检查通过。

### 上电门

1. 不插 FPGA 信号线时检查控制板 5V 输入和 3.3 V LDO 输出。
2. 检查 74HC165/MCP3008 VCC 对地电压。
3. 空载 FSR、轻压 FSR、重压 FSR 分别记录 MCP3008 原始码。
4. 逐一验证按键串行数据，再验证 MCP3008 SPI。
5. 最后连接 LCD 和音频，进行至少 30 分钟连续运行。

## 11. 最终推荐

- 机械位置：采用蓝框下方区域，避免红框 PMOD 被 LCD 遮挡。
- 电气接口：采用第 4.1 节 J13 映射；本地 LDO 产生 3.3 V，V2 固件接入后重新做 Pin Report。
- 传感器：FSR402 + MCP3008，FSR 用硬件分压，SPI 控制线用硬件上下拉。
- 演奏逻辑：12 键选音，FSR 拨弦和力度，多键在一个拨弦事件内同时起音。
- 模式控制：沿用当前 S2 设置入口；控制板提供独立功能键，KEY0 当前已是普通键。
- 蓝牙：增加六针 J_BT，3.3 V UART，供电可选 3.3/5 V，STATE/CTRL 默认隔离，详见第 13 节。
- 代码：一个工程，模块分开；不要为触发、力度、拨弦、选音分别烧录不同程序。

## 12. 扩展要求优化补充

### 12.1 V2 最终功能范围

第二版在原有 12 键、FSR402 和 MCP3008 基础上，增加三项对竞赛扩展要求最有价值的硬件：

1. 三个独立功能键：`MODE`、`PREV/-`、`NEXT/+`。
2. 一个二维摇杆接口：X 轴滑音、Y 轴颤音/音色参数，摇杆按键作为 `ENTER`。
3. 两片 74HC595 和 16 路低电流 LED：12 路琴键指引、4 路模式/节拍/错误状态。

不增加外置 MCU、独立音效芯片、逐键 FSR、第二套音频 DAC 或默认焊接的蓝牙模块。32 复音、两种以上音色、混响、延迟、合唱、实时波形、频谱和李萨如图由 FPGA 与现有 LCD 完成。

### 12.2 74HC165 输入分配

两片 74HC165 共 16 路输入全部使用：

| 数量 | 用途 |
|---:|---|
| 12 | 音符键 |
| 3 | `MODE`、`PREV/-`、`NEXT/+` |
| 1 | `JOY_SW/ENTER` |

这些功能键放在第二版控制板可直接操作的位置。板载 KEY0/KEY1/KEY2 和 S2 保留现有演示/调试用途，新板不依赖被 LCD 遮挡的按键。

### 12.3 MCP3008 通道分配

| MCP3008通道 | 用途 | 输入处理 |
|---|---|---|
| CH0 | FSR402 力度和拨弦 | FSR 分压，`1 kohm + 100 nF` |
| CH1 | 摇杆 X 滑音/弯音 | `1 kohm + 100 nF` |
| CH2 | 摇杆 Y 颤音/音色 | `1 kohm + 100 nF` |
| CH3 | 旋钮或表情踏板预留 | 接口与 `10 kohm` 下拉 |
| CH4--CH7 | 后续扩展 | 测试焊盘与 `10 kohm` 下拉 |

摇杆接口使用 `3V3_LOCAL、GND、JOY_X、JOY_Y、JOY_SW` 五根线。X/Y 中心值由 FPGA 上电校准。FSR 模拟节点仍只使用一个固定下拉电阻形成分压；SPI 数字线继续采用硬件上下拉。

### 12.4 LED 演奏指引

增加 `2 x 74HC595`：

- 12 路对应 12 个音符键。
- 4 路用于 PLAY、力度、拨弦、节拍/错误状态。
- LED 目标电流约 `1--2 mA/灯`，优先采用低电平灌电流点亮。
- 每片 74HC595 电源脚旁放置 `100 nF`。
- `SRCLR_N` 使用 `10 kohm` 上拉，`OE_N` 使用 `10 kohm` 上拉并由 FPGA 控制。
- FPGA 完成第一次有效 LED 数据锁存后，再拉低 `OE_N` 使能输出。

为减少 J13 信号数量，74HC595 与 MCP3008 共用时钟和数据：

```text
ADC_SCLK -> MCP3008 CLK + 74HC595 SRCLK
ADC_MOSI -> MCP3008 DIN + 74HC595 SER
ADC_CS_N -> 只控制 MCP3008
LED_LATCH -> 只更新 74HC595 输出锁存器
LED_OE_N -> LED 总使能
```

ADC 采样不会直接改变 LED 输出；更新 LED 时必须保持 ADC_CS_N 为高，连续发送完整 16 位，再产生一次 LED_LATCH。两种事务由同一调度器串行执行，不能交织移位。LED_LATCH 加 10 kohm 下拉，上电先保持 OE_N 高，锁存全部灭灯码后再使能。

### 12.5 J13 扩展针脚

LED 使用 J13-9/B16、10/B15；蓝牙使用 J13-13/A16、14/A15、15/A20、16/B20。完整合同只维护第 4.1 节，不再保留第二份 J14 映射。模块通过六针 J_BT 插接，不焊死在控制板上。

### 12.6 小于 5 ms 延迟的硬件证据接口

第二版增加 `FSR_SENSE、ADC_CS_N、ADC_SCLK、ADC_MISO、KEY_LOAD_N、KEY_SERIAL_DATA、PLUCK_DEBUG/A14、BT_UART_TX、BT_UART_RX、3V3_LOCAL、GND` 测试点。检测到有效拨弦时，在 J13-7/A14 输出调试边沿；它到模拟音频输出只覆盖检测后的链路，完整延迟还须从真实按键/压力输入变化开始测量，包含采集和滤波时间。

FSR 和摇杆保持 `1 kohm + 100 nF` 的小时间常数滤波，不使用会明显增加演奏延迟的大 RC。MCP3008 目标采样率不低于 `2 kS/s`，建议 `4 kS/s`。

### 12.7 扩展要求对应关系

| 扩展要求 | V2方案 |
|---|---|
| 不少于32复音/并行分量 | FPGA振荡器、包络和混音，不增加PCB器件 |
| 不少于3维演奏表情 | 音符键 + FSR力度/拨弦 + 摇杆X/Y |
| 不少于2种音色 | FPGA音色模块，功能键和LCD选择 |
| 混响、延迟、合唱 | FPGA BSRAM/DDR实现 |
| 不大于5ms延迟 | 小RC、快速ADC、PLUCK_DEBUG实测点 |
| LED演奏指引 | 2 x 74HC595 + 12琴键LED + 4状态LED |
| 波形、频谱、李萨如图 | 现有RGB666 LCD |

| 蓝牙/App | 六针 J_BT：UART + STATE/CTRL，电源互斥选择；BLE GATT 与 App/Web 软件后续适配 |

### 12.8 PCB机械布局冻结建议

推荐从左到右布置为“功能键区 -> 12键演奏区 -> 摇杆区 -> FSR拨弦区”。MCP3008靠近FSR和摇杆接口，74HC165靠近按键，74HC595靠近LED。12颗琴键LED放在对应琴键上方，不放在按键正下方。控制板至少设置4个安装孔，所有操作压力由支撑结构承担，不能传递到J13或LCD FPC。蓝牙放在板边，天线避开 LCD 金属背板、散热器、铜皮及密集排线，按最终模块天线净空要求布局。

## 13. 六针蓝牙接口（2026-10-03 新增）

### 13.1 候选模块与选购条件

用户图片为 Keyes 标识的 CC2541 BLE 4.0 底板，商品图标注 DC 5 V、FFE0/FFE1、6 KB/s。图片不足以确定具体型号、固件、GATT 特征属性、实际传输速率或 AT 命令集，不能直接认定为正品 HM-10。底板 5 V 供电也不代表 UART/STATE 允许 5 V。

本项目目标为安卓 Chrome 在 HTTPS 网页中通过 Web Bluetooth 连接 BLE GATT；需要模块从机/Peripheral 模式、UART 双向透传、可写特征和 Notify 通知。FFE0/FFE1 只有 UUID 名称，尚不能证明读写属性；要求商家给实物版本对应的手册或 GATT 截图。iOS 浏览器、微信内置网页和任意 Android WebView 不作为默认可用平台，APK 封装可能另需原生 BLE 桥接。

采购前确认：

1. 模块 UART TX/RX 及 STATE/BRK 的电平是 3.3 V，提供底板供电范围和六针定义。
2. GATT 服务/特征完整 UUID、Write 或 Write Without Response、Notify，以及 UART 波特率/缓冲限制。
3. AT 手册明确支持更改广播名称、查询固件和波特率；如果需要配对密码，另确认 PIN/绑定/认证能力。改名称不等于支持密码保护，商品上的“Authentication and encryption”不足以确认固件配置能力。
4. BRK 的实际作用、有效电平和内部上下拉。它不等于 HC-05 的 KEY/EN，不据名称猜测 AT 模式入口。

商品标注的 6 KB/s 仅为宣传参数；本链路传音符/控制事件，不作为 MP3 或实时 PCM 音频传输通道。网页现有 HC-05 Web Serial 实现也需新增 BLE GATT 适配后才能使用此模块。

### 13.2 J_BT 插座针序

控制板使用 1×6、2.54 mm 可插拔接口，建议配短转接线。以下 **1--6 是本板自定义编号**，按图片丝印顺序定义；Pin 1 用方焊盘和三角标记。画封装时核对实际模块插合面，不能凭商品图确定直插朝向。其他六针模块若针序不同必须逐线转接，不能直接插入。

| J_BT 针号 | 本板丝印 | 模块端功能 | 控制板连接 |
|---:|---|---|---|
| 1 | `STATE` | 模块状态输出，定义待手册确认 | 可选 0 ohm（默认 DNP）→ BT_STATE → J13-15/A20，FPGA 输入 |
| 2 | `VCC` | 模块底板供电 | VBT，来自互斥的 3.3/5 V 选择，默认断开 |
| 3 | `GND` | 模块地 | 公共 GND → J13-12 |
| 4 | `TXD` | 模块发送 | 经 33 ohm → BT_UART_RX → J13-14/A15 |
| 5 | `RXD` | 模块接收 | 经 33 ohm ← BT_UART_TX ← J13-13/A16 |
| 6 | `CTRL` | 图片模块为 BRK；其他型号可能为 KEY/EN | 可选 0 ohm（默认 DNP）← BT_CTRL ← J13-16/B20 |

TXD/RXD 丝印以模块为参照，另标 `TXD→FPGA_RX`、`RXD←FPGA_TX` 防止同名误接。STATE/CTRL 未用时可不接，四线电源与 UART 即为基本通信链。

### 13.3 供电、默认电平与器件预留

- JP_BT_PWR 用三针选择座：1=3V3_LOCAL、2=VBT、3=5V_IN，**出厂不装跳帽**。仅允许 1--2 或 2--3 二选一，严禁同时短接。用户图片这款若实物手册确认底板输入为 5 V，再选择 2--3；裸 CC2541 核心板不能接 5 V。
- VBT 旁放 100 nF + 10 uF，测量点标 VBT/GND；核对模块峰值电流、LDO余量及所选供电器件额定值。
- FPGA UART_RX 侧放 47 kohm 上拉到 3V3_LOCAL；模块 RXD 的空闲电平及掉电漏电按实物手册核对，预留弱上拉焊盘但默认 DNP。33 ohm 仅抑制边沿，不是 5 V 电平转换器。若模块输出不是 3.3 V，必须先增加适当电平转换再连接。
- STATE 在 FPGA 一侧可装 47 kohm 下拉；连接电阻默认 DNP，因此模块侧不被预设电平加载。CTRL 的模块侧预留互斥上拉/下拉焊盘，默认均 DNP，拉到哪条电源及电阻值由最终手册确定，不拉到 VBT/5 V。固件未适配时保持 CTRL 高阻，不主动输出。
- 两个辅助信号按输入/输出固定方向预留，不短接、不直接接 5 V。要使用 RTS/CTS 的模块需重新定义接口与固件，不能宣称本六针支持硬件流控。
- 默认控制板与模块同开同关；VBT 断开且 UART 接通不等于彻底断电隔离。调试时应先断整机电再拔插/换跳帽，禁止用 USB-TTL 给模块另一路供电而通过 IO 反向给 FPGA 或模块供电。
- 图片约 48×17 mm 尺寸只能用于预留空间，不能据此冻结模块排针方向、底部器件高度及天线净空；留转接线与安装空间。
