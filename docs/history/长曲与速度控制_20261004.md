# 第五阶段：长曲、休止符与调速

第四阶段双曲目已完成永久烧录，用户反馈“效果正常”。第五阶段以此为回退基线，补齐单声部曲谱的时长表达与容量。

曲谱地址从 6 位扩为 8 位，最多 255 行；音符间隔和发声 gate 分别计时。曲谱用 96 tick/拍表达节奏，经独立时长转换模块送给采样驱动播放器。速度提供 80/100/120/150 BPM，由现有“拓展要求 → 曲目演奏”行的 KEY2 在准备后循环调整，不新增菜单页或占用演奏页按键。

《小星星》改为两遍旋律、中间两拍休止，85 行、84 音符、98 拍；《欢乐颂》保留原旋律。LCD 显示速度及三位进度。歌曲使用专用快速平滑释放，普通手动演奏 ADSR 不变。发声与音符间隔分开后，八分音符无需再扣掉固定 150 ms；150 ms 仅保留在进入、换曲、重播的保护阶段。

验证使用正式音频链：完整长曲、独立 255 行极限曲谱、休止行、超过 65535 采样的长音、四档速度、附点/八分音符、事件背压与取消、菜单与帧边界显示，并回归既有音视频功能。测得结果与最终位流见 `artifacts/song_transport_stage5_20261004/validation.md`，仿真不等同于实物听感。

后续应先验收此版本的节奏和音符衔接，再将曲谱事件接入多声部调度；当前未实现任意 MIDI 上传或多轨伴奏。
