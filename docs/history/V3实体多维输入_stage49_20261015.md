# V3 实体多维输入开发记录（Stage49，2026-10-15）

实际硬件更新：stage49/50 是旧接口提案的逻辑验证，不能用于本次 V3 接线。2026-10-15 收到的原理图采用两颗 MCP3008、12 路独立 FSR，摇杆已焊接；实际引脚与新程序见 [stage51 适配](hardware/V3实际引脚与程序适配_20261015.md)。下文保留历史证据。

本轮针对赛题基础多维交互、实体多键复音和拓展二的连续表情输入，未新增拓展四功能。源码位于 `work/v3_inputs_stage49_20261015`，从 stage47 独立建立；V2 已烧录的 stage42 不变。

## 已实现

| 部分 | 实现与行为 |
|---|---|
| 琴键扫描 | 两片 74HC165 采集 12 个半音琴键和 MODE/PREV/NEXT/ENTER；先读初始 H，再移位；每键连续四帧消抖 |
| 模拟采集 | 一片 MCP3008 顺序读 CH0 压力、CH1 摇杆 X、CH2 摇杆 Y；1 MHz SPI；片选间隔至少 1 µs；三通道完成后发布整帧 |
| 自动校准 | 全部按键松开、压力原码 ≤128、摇杆两轴在 256～768 时，等待 8 帧，再用 32 个稳定样本取得压力零点与摇杆中点；偏离首样本超过 8 码重新累计；复位后重校准 |
| 跨时钟 | 系统域扫描，完整 76 位快照握手送入音频域；两域耦合复位、分别同步释放；约 5 ms 未收到完整帧则禁用实体演奏 |
| 复音与表情 | 12 键经音符事件进入既有 32 声部 DDS 音源；压力控制力度，X 控制弯音，Y 控制颤音深度；保留原 ADSR、音色、混音和音效 |
| 音符可靠性 | 事件背压时保持完整负载；释放优先；等待中的 ON 仍有对应 OFF；菜单/超时恢复后，必须先松开原按键才能重新起音 |
| 显示与灯带 | 原 RGB LCD 与 WS2812 使用声部库实际按下音符掩码；LCD 状态保持帧边界提交；不恢复 HDMI 或触摸 |
| 调试输出 | `pluck_debug` 在声部库接受 ON 时产生一个音频时钟周期脉冲，约 20 ns；它标记数字事件接受，不代表模拟按压起点或 DAC 首音 |

设计依据为 [V3 封装与引脚分配](hardware/第三版封装与引脚分配.md) 第 6.1/6.2 节。该表是设计基线，当前没有最终 V3 原理图/PCB 可供逐网核对。因此本候选的 `v3_instrument_top.gprj` 无 CST/SDC；旧 `fpga_instrument_av.gprj` 只用于回归列源，不可用于 V3 物理构建。

## 验证

- 五项新增专项测试通过：165 位序/消抖/复位，ADC 命令及完整帧，校准与连续表情，音符背压及释放，生产顶层整机联动。
- 全量回归 **105/105 通过**，原有 100 项全部保留且通过。执行目录为 `E:/Gowin/workspace/v3_inputs_stage49_20261015`。
- 整机测试通过实际 SPI/165 串行模型输入四键和弦，检查四声部发声、压力与摇杆控制、PT8211 引脚解码、LCD 帧边界及灯带音符掩码、实体 MODE、超时与恢复。仅替代 PLL 时钟/锁定，不注入 PCM、按键快照或音符事件。数字 PCM 与串行解码峰值均为 8984，该测试未削顶。
- 原 V2 FSR 生产参数 60 组延迟测试仍通过：右声道首非零最差 3.498 ms，达到 33 LSB 最差 3.561 ms。**这是 V2 路径回归，不能作为新增 V3 路径的延迟结论。**
- 综合成功，实际顶层 `v3_instrument_top`，器件 `GW5AST-LV138PG484AC1/I0`；MCP 构建 ID 为 `9f489171ff844bae9a765f0f229ba740`，构建期间输入指纹未变。没有进行 P&R、时序验收或烧录。

综合日志零错误，90 条告警：86 条 EX3791 位宽截断、2 条 NL0002 未用模块优化、2 条 CK3000 跨 PLL 关系。新增六条截断来自校准累计与平均：32 个 10 位样本的总和最大为 32736，15 位累计寄存器容得下；除以 32 后最大 1023，10 位结果容得下。新增未用模块告警是 V3 替代旧手动 `performance_controls` 分支后的预期优化；另一个是原曲谱 ROM。未新增多驱动诊断或锁存器。
