# 第四阶段：双曲目演奏

此次把第三阶段的可替换曲谱接口接入第二首真实曲目。原《小星星》保持不变，新增《欢乐颂》主旋律，两首均通过正式 DDS/ADSR 链路发声。

曲目页面：KEY0 选曲并开始播放；KEY1 停止；KEY2 重播；S2 返回设置。LCD 显示中文曲名、运行/停止和当前音符进度。设置页最后一行沿用“曲目演奏”入口，不增加试听目标数量。

《欢乐颂》采用 C 大调两段主旋律，共 30 次起音、32 拍，100 BPM。它包含附点四分和八分音符；开头 E E F G，与《小星星》C C G G 容易区分。不是贝多芬整部作品或多轨编配。

换曲时清除待发事件、释放当前声部，等待原 7200 音频采样间隔后再起音。播放器保留当前音高供旧包络释放，只有收到新 ON 才换音高。选择键边沿在控制器识别；菜单与普通演奏不响应歌曲换曲。所选曲目仅在运行期间保留。

为显示“欢乐颂”，复用原微软雅黑粗体点阵生成工具，保留已有 0～125 字形编号，新增 126～128。字形索引与 ROM 地址一起扩宽。LCD 继续使用同步字库、原渲染流水线与帧边界状态提交。

针对性验证覆盖完整《欢乐颂》的音高、起音时间、释放、结束及 PCM；播放中/停止后换曲、长按、快速换曲、重播、停止/S2 优先和返回菜单后保留选曲。LCD 测试覆盖两个曲名、42/30 进度、KEY0 提示、扩展字形地址与帧边界；UART 测试覆盖动态总数。最初截图发现的提示遮挡电平条和琴弦超时字段混用已经在最终源码修正。

原理图、引脚、音频采样率和时序约束不变。新软件不依赖蓝牙模块或第二版硬件；本轮仅构建验证，未烧录。完整结果见 `artifacts/song_select_stage4_20261004/validation.md`。
