# 拓展四第一步：FPGA 独立演奏《小星星》

本阶段先打通“曲谱 → 音符定时 → FPGA 合成 → 扬声器 → LCD 同步显示”。歌曲由板卡独立合成，不依赖电脑、蓝牙或录音文件。当前实现固定主旋律，后续再扩展可下载曲谱与伴奏。

## 演奏内容

《小星星》采用六句 A B C C A B，共 42 个音符、48 拍，速度 100 BPM，旋律约 28.8 秒。使用现有琴音与触动 ADSR，固定力度 96；每次换音前留出自然释放时间。启动和重播先等待约 150 ms，避免上一音尾音被直接改调。

歌曲只演奏一遍，结束保持停止，不自动循环；上电后仍进入原来的日常演奏界面。

## 烧录后的操作

1. 按 S2 进入设置，在页签处用 KEY2 选择“拓展要求”。
2. 用 KEY0 移动到最后一行“对比试听”。
3. 用 KEY1 循环选择，直到显示“曲目演奏 小星星”。
4. 按 KEY2 准备，再按 S2 返回演奏页，开始播放。
5. 演奏页按 KEY1 停止、KEY2 从头重播；按 S2 停止播放并返回设置。

LCD 显示“小星星”、运行/停止、琴音及 01/42～42/42 音符进度；琴键按当前音高高亮。原有波形、频谱和李萨如仍取正式音频通路。

## 板上验收

- 听到熟悉的完整六句旋律，重复同音能分开，结束后停止。
- 观察进度从 01/42 到 42/42，琴键高亮随旋律移动。
- 中途按 KEY1 能停止；按 KEY2 从第一音重播，长按不应反复重启。
- 按 S2 能进入设置；退出曲目选择后仍能使用原有演奏、试听和可视化功能。

## 实现与证据

源码候选为 `work/song_demo_20261003`，最终交付归档为 `artifacts/song_demo_20261003`；最终构建、时序和烧录状态以归档中的 `validation.md` 为准。

新增 `song_player.v` 保存音符与时值，并产生按采样节拍推进的 gate/trigger/note。顶层将这些事件接入已有 DDS、ADSR 和输出链，复用原有状态快照同步到 LCD。原七种对比试听之后新增第八个曲目入口，不增加设置页行数。

DDS 入口将全部控制参数、触发、门控和采样使能共同寄存一级，分开发声源选择与 DDS/ADSR 运算，避免新增歌曲后把组合路径拉长。该级约延迟一个音频时钟周期，下游效果器仍在原来的采样节拍读取上一采样；仿真逐拍对照及整曲 PCM 对照用于检查对齐，而非仅检查能否发声。

验证包含独立曲谱及时长检查、正式控制器与音频链的整曲仿真、LCD 中文与帧同步检查，以及既有功能回归。`sim/song_twinkle.wav` 是 RTL 仿真导出的音频预览，不是板卡录音；最终听感仍需烧录后确认。

下一阶段将固定曲谱替换为统一的音符事件队列，再接电脑曲谱导入、串口和蓝牙传输；实时发声与节拍调度继续由 FPGA 执行。
