# FPGAvedio 使用与演示

电脑应用保留原播放器模式，并提供 FPGA 播放模式。左侧功能导航按流程跳转；右侧 BLE 连接；三种图形分开显示，板端联动图形放在后部。

1. 准备曲目：导入有权使用的普通音频/MIDI，或从播放器当前歌曲进入 FPGA 工作台。平台仅开放试听或拒绝音频时，不代表可以获取完整歌曲。
2. 纯音乐转谱：导入普通音频，默认最短识别音长 100 ms；完成本地识别后，可用“试听识别音符”核对。复杂伴奏、鼓点与混响仍可能影响音高/节奏；MIDI 或准确曲谱通常更可靠。
3. FPGA 演奏准备：选择开始/结束时间，点击“一键生成演奏曲谱”，再用“试听 FPGA 演奏参考”检查实际待上传版本。高级设置默认折叠，不需要逐项填写；原识别结果保留。容量以真实设备 CAPS 为准，不静默截断。
4. 连接右侧 BLE，选择“行者无疆”；识别设备、读取上传能力。仅连接成功不等于 FPGA 已响应。
5. 上传并等待所有分块及整曲 CRC/COMMIT ACK，之后单独点击播放。丢包重试、取消与超时按协议处理，不用本地计时假装板端已执行。
6. 检查 HDMI/灯带和实际声音。上传保存在 FPGA RAM；断开电脑后可以继续，断电则丢失。

## BLE 主用与 USB 备用

默认保持 BLE“行者无疆”。有线备用需本次配套 ESP32-S3 固件与原生 USB Serial/JTAG 接口（GPIO19/20）；普通 USB 转 UART 接口不能代替。先停止并确认、断开 BLE、等待至少 3 秒，再手动选择 USB 和对应串口；握手后重新检查 FPGA 能力。异常断线还可能需等待 5 秒租约到期和 UART 排空。不会自动切换、续传或重放播放命令；断线也不表示板端停止。

上传显示 FPGA 确认的有效速度、耗时与重试次数，USB 桥接排队确认不代表 FPGA 已执行。赛前完成本地转谱并保存/导出曲谱库，BLE/USB 上传不需要 Wi-Fi；小智云端语音仍需要互联网。配套固件持续重连保存的热点，不会仅因等待超时就停止站点模式。没有 ESP Flash 歌曲永久缓存。

连接模块的系统关系见 [工程原理](ARCHITECTURE.md)。桌面更新须完全退出并重启，个人曲谱保留。Android WebView 不支持 Web Serial 时禁用 USB 选项，BLE 路径保留。

## 纯音乐推荐设置

默认演奏方式为“和弦与延音 · 推荐”，保留识别出的和弦与完整长音，20 ms 起音归组、60 ms 最短保留音、原始节奏、不折叠重复音。原生 MIDI 48–83 音高不变，超范围低、高音区分别统一移动八度；不能容纳的音符明确报告。容量上限通常为 2048 个完整音符，满容量时保留全曲覆盖并报告删减；过长曲目可缩短选段。板端显示使用“显示引导”单声部轨，实际播放两轨，不重复音符、不因显示截短长音。

“单声部旋律 · 旧版兼容”保持原算法。保留原始节奏时不使用 BPM 和拍点偏移；可展开高级设置手动量化。点击“恢复纯音乐推荐”只重置参数，须再次生成才改变待上传曲谱，不会悄悄替换正在使用的版本或选段。旧存档和已上传歌曲不会自动补回和弦，必须重新生成并上传。

“试听识别音符”检查原始音符结果；“试听 FPGA 演奏参考”使用实际上传的音高、力度与量化时刻，并近似模拟板端的钢琴谐波、衰减包络与高频补偿，帮助发现电脑试听与板端重奏的差异。参考试听不是板端音频回传，也不包含 ROM 整数舍入、最终饱和、DAC/功放/扬声器特性；使用旧固件时包络也不同。板端速度设为 100% 才能直接比较节奏。

歌曲包络优化仅调整歌曲路径：起音后衰减到峰值的 50%，释放沿用原算法；上传曲目采用干声，避免菜单残留的效果器改变节奏听感，退出歌曲播放后恢复手动演奏的效果器选择。12 键手动演奏与物理弦算法保留。2026-10-24 上位机后补默认复音整理，无需重新烧录；仍是音符识别后重奏，不保证原曲配器、鼓点或音色还原。原理见 [曲谱管理与转谱](ARCHITECTURE.md)。

新音频转谱从原音频的基频及谐波能量估算相对力度，避免把模型识别置信度当作音量；它不能分离独立乐器。复音模式默认“移调低音力度”60%，给上移八度的低音留出空间，可在高级设置改为 40%/80%/100%。需要重新转谱、生成、上传才能同时应用两项处理；旧存档仅重新生成不能补算声学力度。详见 [力度与低音平衡优化](伴奏力度与低音平衡优化_20261024.md)。

## 两种可视化

- 本地试听波形/频谱/李萨如：来自电脑端试听，不表示 FPGA 在发声。
- FPGA 联动：琴键/状态由真实板端回包更新；波形、频谱、李萨如来自 SCOPE1 有限音频快照，必须连接并取得真实数据。不承诺持续实时音频流。

## 注意

MP3 不会以原声上传，而是识别音符后用 FPGA 音色重奏。音频识别提取音高、起止时刻和力度，板端按乐器音色重奏。Android 源码在 `host/mineradio/android`，签名私钥不上传；重建不同签名不能覆盖旧安装。电脑打包入口是 `npm run build:fpga:dir`，不是上游自动发布配置；本派生版自动更新已禁用。

子目录原 README 保留上游和历史记录，其中旧版本编号、512 事件、9600 和“255 音符”等旧描述不代表当前容量/串口设置；当前状态以根 README、docs/RELEASE.md 和设备 CAPS 为准。
