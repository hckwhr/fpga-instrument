# 节奏模式界面与启动修复

12 条固定轨道与实体压力键从左到右对应。新增流光背景、命中粒子、展开舞台，
也可选择减少动态；动效不改变判定线或按键位置。

默认自动配键：不超过 12 种且处于板端支持音域内时保留原音高。
超出范围明确提示，用户可选择八度折叠生成练习谱。该操作不改写原曲谱，
界面报告音高调整和同刻同音合并数量。

练习启动等待已在途的通信完成；节奏页面暂停后台状态/音频查询，避免争用。
板端拒绝原因显示在开始按钮下方，持续保留并允许重试。不会把 BLE 桥接应答
当成 FPGA 已开始，也不能通过点击屏幕假冒实体按键命中。
