引擎测试覆盖：跟练等待、和弦、提前按下、按住不连击、松开重奏、Perfect/Good 实际毫秒窗口、漏按静音、暂停时间排除、重置、整曲结束、无效/超过 12 音高的曲谱拒绝、同刻同音合并及单调时钟要求。

运行中发现画面帧时间戳可能早于同帧输入时间戳，已统一采用 `performance.now()`；最终桌面与手机页面测试均通过。练习不发送自动播放或自定义硬件指令。

硬件限制：这一轮声音来自电脑/手机；实体 RGB 提示、压力键输入和 FPGA 本地判定仍需配套固件扩展。手机尺寸测试不等于已安装新版 APK。本轮未烧录 FPGA 或 ESP。

复现入口：`host/instrument-web` 中运行 `npm run build`；`host/mineradio` 中运行 `npm run prepare:fpga`、`npm run build:fpga:dir`、`node tools/desktop-smoke.mjs` 和 `node tools/app-smoke.mjs --player`。实际工具链路径见已有构建说明。
