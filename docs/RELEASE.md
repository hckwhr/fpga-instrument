# 工程功能说明

## 演奏与声音

当前工程以 32 复音为通用演奏与曲谱重奏核心，提供 8 路物理弦模式。12 路压力键产生起音、释放和力度信息，摇杆与旋钮提供表情及参数控制。菜单管理音色、音区、滑音、弯音、颤音和效果器。

声音路径由音符事件、声部分配、波形或波导计算、包络、混音及 DAC 发送组成。手动演奏与歌曲重奏使用统一事件表达，并按模式选择音源。

## 显示与灯光

底板 HDMI 输出 800×600 @56.25 Hz，800×480 面板居中。界面包含菜单、演奏状态、压力曲线、波形、频谱和 XY 余辉。RGB 灯带关联键位与歌曲引导，形成声音、画面和灯光的共同反馈。

## 上位机与曲谱

FPGAvedio 提供播放器和 FPGA 工作台双模式。工作台按导入、转谱、选段、试听、连接、上传、播放的顺序组织功能，支持 MIDI 与普通音频、和弦与延音整理、相对力度、低音平衡和曲谱库。

曲谱通过 ESP32-S3 转发到 FPGA，板端存储后独立调度播放。BLE 为主连接，USB 为手动备用。小智通过 Wi-Fi 语音服务调用支持的播放和状态命令。

设计细节见 [工程原理与结构](ARCHITECTURE.md)，操作方法见 [上位机使用](HOST.md)。
