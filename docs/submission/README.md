# 作品技术设计报告

- [Word 正文](灵弦FPGA多维交互乐器_技术设计报告.docx)
- [PDF 阅读版](灵弦FPGA多维交互乐器_技术设计报告.pdf)
- [Markdown 内容源](灵弦FPGA多维交互乐器_技术设计报告.md)

采用官方技术文档模板，分为作品概述、系统组成及功能说明、完成情况及性能参数、总结和参考文献。报告共 42 页，含 17 幅图与 16 张表，说明电路连接、输入采集、事件身份、声音算法、显示、通信及应用分工，并包含定点计算示例、存储与链路预算、典型操作流程。

实物交互采用十二个压力键、双轴摇杆和菜单按键。X 轴控制弯音，Y 轴控制颤音深度；预留的模拟增益输入不列为实体调节功能。功能介绍、通道表和系统框图采用相同表述。

`assets/` 保存正文插图。`figures/` 提供 8 张工程原理图的 SVG 和 PDF 矢量版本，便于后续编辑及制作答辩材料。图中统一区分输入、控制、音频计算和输出；箭头表示数据流或处理顺序，虚线用于等待分支。流程图使用 Matplotlib 绘制，Word 内置图使用 600 dpi PNG。

音频接口依据实际 PT8211 DAC 说明，未将其右对齐格式写成标准 Philips I²S。资源与时序数值采用当前实现报告。
