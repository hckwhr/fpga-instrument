# 纯音乐演奏优化 stage65

本轮目标是简化音频到 FPGA 的操作，并缩小电脑试听与 FPGA 重奏的差异。不做人声分离，不改变 SONG2 协议、4096 事件容量或 UART 115200，不承诺完整伴奏还原。

本文保留原开发目录用于追溯；本仓库对应源码为 `fpga/stage65/`，验收归档为 `artifacts/stage65/`。当前构建入口见 [BUILD.md](BUILD.md)，原始报告内的绝对路径不作为新机器入口。

## 上位机

- 转谱默认最短音长从 120 ms 调为 100 ms；保留 80/100/120/180 ms 选项。80 ms 在本轮合成 MP3 样本中产生多余尾音，因此没有直接用作默认值。
- 演奏准备保留“选段 → 一键生成”主操作，高级参数默认折叠；一键恢复推荐设置。生成动作明确创建派生曲谱，原识别结果仍保留。
- 推荐参数：均衡主旋律、20 ms 起音窗口、60 ms 最短保留音、原始节奏、重复音保留、乐句音区整理、长音保护、音域 MIDI 0–127。保留原节奏时不使用 BPM/拍点偏移，减少错误量化。
- 两种试听明确区分：识别音符检查转谱；FPGA 演奏参考使用实际待上传音符，近似模拟 stage65 钢琴波形、48 kHz 包络和高频补偿。
- 桌面 FPGAvedio 的共用界面已更新，重启应用生效。保留播放器、BLE、停止播放、曲谱库和两类可视化功能。

## FPGA

候选目录 `work/v3_instrumental_stage65_20261024`，独立构建目录 `E:/Gowin/workspace/v3_instrumental_stage65_20261024`；不覆盖 stage64。

- `polyphony_bank_32` 新增默认关闭的 `SCORE_ENVELOPE_ENABLE`；生产顶层启用。仅歌曲事件模式且非实时表情时，起音后每 8 个采样衰减 1，到峰值 50% 保持；OFF 沿用有界整数指数释放。
- `av_top` 新增默认关闭的 `SCORE_PLAYBACK_ENABLE`；上传曲目播放时选干声，退出后恢复手动演奏的效果器选择。
- 32 份独立复音状态、8 条物理弦、手动演奏、时钟/复位/CDC、45 引脚保持原配置。未新增宽泛时序例外。

## 验证边界

当前转谱整理依然是单主旋律提取，不是完整和弦/伴奏重构；复杂纯音乐也可能漏音或误识别。参考试听不是 DAC 采集，ROM 插值/整数舍入、最终限幅与硬件声学链路可能不同。实际音质改善须在获准烧录后对同一首曲目 A/B 试听。
