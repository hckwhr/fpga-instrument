# 单仓库整理说明

2026-10-27 将最新已烧录 FPGA 版本整理到 fpga/current 和 artifacts/current。生产输入、位流、网表及报告逐字节复制并校验，旧源码和失败证据不覆盖。原始工作目录名称与日志内部编号保留，不作为对外产品版本名。

根 README、版本说明、硬件导航和通用构建入口指向 current。源码内构建所需标识、历史测试参考和原始证据不进行全局替换，以免破坏引用或追溯；面向使用者的当前文案移除内部开发编号。旧版本说明可通过 Git 历史及归档查阅。

SOURCE_MANIFEST.json 记录文件来源、源 SHA256 与交付 SHA256。FPGA RTL、PLL、CST、SDC 和工程输入未因整理而改变；新增文档与通用入口不是原构建输入。运行以下命令核对文件：

```powershell
pwsh -NoProfile -File tools/verify-manifest.ps1
```

仓库不包含工具安装包、依赖缓存、个人音频/录音、账号凭据、设备身份或上游 Git 目录。三个源码组件共同置于本仓库，未嵌套为子模块。

测试中的固定参考只用于回归，不代表当前波特率或烧录版本。当前 UART 为 115200。历史脚本中的开发机路径需要核对后才能运行，尚未改造成跨机器一键发布流程。

本次 FPGA 整理归档 376 个源文件及证据文件；大体积布局数据库未纳入 Git，位流、实施网表与报告已保留。最新硬件验证边界见 artifacts/current/validation.md。
