# 单仓库整理说明

统一目录保留当前生产源码，排除无关历史工作区、工具安装包、缓存、个人/账号/设备状态和上游 .git。没有把三个项目嵌套为子模块，克隆一个仓库即可取得选定源码。

`SOURCE_MANIFEST.json` 记录文件来源、原始 SHA256 和整理后的 SHA256；新增文件没有原始来源。生产 FPGA RTL、PLL、CST、SDC 保持逐字节不变。新增根文档与 tools 入口；为适配目录，将桥接黄金向量、stage42 设备识别参考和旧整机联调的相对引用改到 tests/ 下。新增文档/适配文件不冒充原构建输入。运行 `pwsh -NoProfile -File tools/verify-manifest.ps1` 可校验交付文件。

桌面冒烟使用系统临时目录建立独立浏览器配置；测试输出留在忽略目录。小智屏幕测试改在自身 build-host 生成工件。保留 stage64 实际解析的 dependencies.lock，并调整组件忽略规则以便提交；sdkconfig、设备 NVS 和个人状态仍不提交。

`tests/reference/stage59b` 只是历史 9600 波特率整机离线联调的固定参考；当前 stage64 真实 115200 通路由 tb_scope_115200 等套件检验，不能将旧参考当成当前位流。

归档中的报告路径、历史参数和运行中快照保持原貌，当前权威状态见根 README 和 docs/RELEASE.md。厂商手册、原软件安装包、所有失败实验和设备备份不全部上传，不影响三个当前源码工程的分类交付。
