# 暖色工作台：设计与评审记录

## 日夜主题增量（2026-10-03）

使用 ui-styling 的语义颜色变量方法，在页头增加日夜切换按钮。默认保留暖白天模式，夜间采用深棕灰背景与浅陶土强调色；选择保存在本机，首次绘制前恢复。手机窄屏将操作区放到品牌下方。按钮支持键盘操作及读屏开关状态；浏览器禁止本地存储时仍可切换，但不记忆。

画布与表单共用颜色变量，切换只重绘，不重编译曲谱或停止试听。取消按钮颜色过渡，避免主题切换瞬间的浅色残留。

验证：构建和11项单元测试通过；Edge 实测键盘切换、跨导航记忆、画布像素更新、6音符曲谱往返切换一致、切换时试听持续。真实 MP3 转谱回归通过，40秒样本前30秒/整首仍为6/12音符。390px/320px无横向溢出，640px文字两倍放大通过。夜间辅助文字对比6.66:1，主按钮7.49:1，控件边界3.86:1，均达到对应AA阈值。

已看图核对：[夜间桌面](evidence/theme-dark-desktop.png)、[夜间曲谱](evidence/theme-dark-notes.png)、[夜间手机](evidence/theme-dark-mobile.png)。真实硬件和读屏器未在本轮测试。

## 方向和结构

2026-10-03，依据用户指定的参考页和“暖色、合理布局”要求。页面为乐器曲谱工具，面向需要导入音乐、转谱、试听的使用者；不是宣传页。

使用共享 ui-design 工作流。用户暖色方向替代默认 Nothing 黑白风格，不混入其他风格执行器。实现保持原生 HTML/CSS/JS；无需新依赖、图片或在线字体。执行设计后，用 review-ui-design 单独进行视觉、交互、系统与可访问性复评。

色彩：米白 #f5f1e9、纸白 #fffdf9、浅沙色 #eee6d9，陶土主色 #945738，正文 #3f3731、辅助 #6b5e54；成功使用深绿、错误使用暗红，均有文字说明。中文界面使用 Segoe UI / PingFang SC / Microsoft YaHei，数字使用 Consolas 以便比较。标题 30px、分区标题 15px，正文/控件 12–14px。布局以 8/16/24px 为主要间距，外分区圆角16px、控件7px，无装饰阴影、渐变和发光。

桌面：左侧导入/识别，右侧音符/试听/导出；源文件音频与 MIDI 是同级标签页，支持方向键切换。识别细节与设备调试按需展开。手机以相同任务顺序堆叠，不使用固定底部栏。完成状态、空状态、禁用、错误、焦点及长文件名换行均明确处理。

## 问题与复评

| 编号 | 优先级 | 原问题、影响 | 改动与复评结果 |
|---|---|---|---|
| V1 | P1 | 深蓝背景、荧光强调与用户要求的舒适暖色冲突；多个大圆角卡片争抢视觉权重 | 已解决：两区输入/结果结构、统一暖色，音符图改为米白琴键及陶土音符 |
| I1 | P1 | 蓝牙与文本测试占据首屏，导入音乐需要向下寻找 | 已解决：设备区折叠到工作台下方，顶部连接状态提供可聚焦入口 |
| I2 | P1 | 音符图、试听、调整、导出分散在纵向多个区块 | 已解决：结果区集中处理；左侧文件名与右侧结果名各自标明对象 |
| A1 | P1 | 暖色初稿辅助文字对比4.35:1、控件边界2.70:1，偏浅 | 已解决：辅助色加深，对比5.06:1；主按钮文字5.62:1；控件边界在沙色上3.13:1。数值来自源色值脚本计算 |

保留能力：所有曲谱转换、原音频播放、音符试听、导出和串口功能；连接状态继续区分串口打开与板端协议确认。未新增后端行为或“上传成功”状态。
