# FPGA 共用转谱与上传前端

此目录为 FPGAvedio 桌面/Android 工作台提供共用转谱、曲谱库、可靠上传、播放控制及可视化。当前硬件版本以仓库根 [README](../../README.md) 与 [交付记录](../../docs/RELEASE.md) 为准。

## 使用流程

导入音频或 MIDI → 选段 → 识别与生成演奏曲谱 → 参考试听 → 连接设备并读取能力 → 上传确认 → 播放/停止。

默认“和弦与延音”保留识别出的复音、重复起音与长音；从原音频估算相对力度，移调低音默认 60%。保留旧单声部兼容模式，容量删减明确提示，不覆盖原识别结果。曲谱上限 4096 事件，起音和释放分别计数，实际以设备 CAPS 为准。

音频转谱是音符识别后重奏，不传输 MP3 原声。参考试听近似模拟板端，不包含完整 DAC/音箱特性。曲谱保存在 FPGA RAM，断电丢失。

## 连接与显示

BLE 主用，设备名称“行者无疆”，采用 NUS 服务；USB 为手动备用，需配套 ESP 固件和原生 USB 接口。模式切换前停止、断开并等待串口事务释放，不自动重放命令。业务 UART 为 115200、8N1，接线见 [硬件说明](../../docs/HARDWARE.md)。

连接成功不代表 FPGA 响应，上传提交 ACK 不代表已经播放，播放 ACK 不代表音频实测。板端波形、频谱和 XY 来自有限数据快照；本地试听图形与板端数据独立。

## 开发入口

```powershell
npm ci
npm run build
npm run test:audio
```

浏览器与音频开发工具使用本机浏览器及 ffmpeg。完整命令见 [构建方法](../../docs/BUILD.md)，转谱与上传的模块关系见 [工程原理](../../docs/ARCHITECTURE.md)。

src 下按曲谱解析、音频识别、事件整理、设备会话、传输接口和可视化拆分模块；tests 与 tools 保存相应开发用例和构建工具。
