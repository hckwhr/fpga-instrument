# 节奏大师（上位机练习模式）

FPGAvedio 有三个入口：播放器、FPGA 播放、节奏大师。桌面通过顶部按钮切换，手机通过左侧功能菜单切换。三个模式共用同一个曲谱工作台和连接会话，切换不会重新创建 BLE 连接。

## 使用

1. 打开节奏大师，选择《小星星》《欢乐颂》、FPGA 工作台当前曲谱或本地曲谱库。
2. 选择跟练或挑战，点击开始练习。两秒准备后，音符沿轨道落到判定线。
3. 电脑使用 `A S D F G H J K L ; ' Enter`；手机触摸音名对应的琴键。只在按对时合成声音，等待、漏按或错按不播放曲谱音频。
4. 跟练会在当前起音处等待，和弦的所有音都命中才继续。挑战保持时间推进，按起音偏差记录 Perfect（±70 ms）、Good（±160 ms）和 Miss。
5. 同一个键需松开后重新按下，长按及操作系统键盘连发不会重复计分。支持同时按多个键；部分电脑键盘存在硬件键位冲突，不能将其视为乐器压力键故障。
6. 暂停、切换模式、窗口失焦或进入后台会暂停练习并释放声音。返回后需主动继续，不自动恢复播放器音乐。

开始、暂停和重来在琴键画面上方。修改曲谱、速度或练习方式会重开本次练习。完成后显示命中数、最高连击、错按数和完成分。当前只对起音计分，长音提前松开会停止声音，不评价保持时长。

## 使用自己的曲谱

在 FPGA 播放中导入音频或 MIDI，完成转谱/音轨选择后，点击“用当前曲谱练习”。也可保存到曲谱库后在节奏大师中选择。曲谱库保存的是源音符，载入时只应用一次原有速度与力度设置，练习速度是其上的独立倍率。

固定 12 个键位，编号 01—12 对应左到右的位置，换曲不再重新排列。可选择 C 大调白键（C4、D4、E4、F4、G4、A4、B4、C5、D5、E5、F5、G5）或半音阶（C4—B4）。曲谱包含键阶之外的音高时明确拒绝；不自动删音、移调或折叠八度。同刻同音的多轨音符合并为一次按键，保留较长时值和较强力度，并显示合并数量。节奏大师不改写板端自定义键位。

舞台使用近宽远窄的透视轨道，音符、长音尾迹和节拍线共用投影。宽屏左侧显示得分和连击，右侧保留曲谱与练习设置；手机竖屏的触键分成两排，以编号对应上方 12 条轨道。继续沿用播放器背景、字体及三模式切换。

## 硬件边界

这一版输入来自电脑键盘/触屏，发声来自本机 Web Audio；轨道与琴键颜色只是屏幕提示。

当前板端 `PERF1` 仅提供键位配置和录音控制/回传，没有带时间戳的实时压力键事件、节奏练习会话或 RGB 提示命令。因此本模式不推断硬件按下状态，不发送虚构命令，也不宣称已实现实体 RGB 指引后按键发声。已有板端自动播放不会被本模式擅自停止，练习前请在 FPGA 播放中停止板端曲目。

后续实物联动需单独扩展 FPGA/ESP 协议，并在 FPGA 本地完成判定与起音，避免 BLE 延迟影响音符触发；上位机接收带序号的判定结果用于动画和得分。不能将这一版的电脑按键计分冒充板端演奏测量。

## 维护与验证

- `src/rhythm-engine.js`：可独立测试的曲谱校验、时间推进、按键判定和计分。
- `src/rhythm-audio.js`：只由命中事件启动的本机合成音，松键/暂停释放。
- `src/rhythm-view.js` / `src/rhythm.css`：共享桌面/手机界面、曲谱来源及生命周期。
- `npm run build`：语法检查、原有测试及新增节奏测试、离线资源构建。
- Mineradio 的 `tools/desktop-smoke.mjs`：实际打包应用中的模式切换、静音直到命中、松键重奏、原工作台回归。
- `tools/app-smoke.mjs --player`：手机尺寸浏览器中的菜单入口、触摸命中与原有转谱上传回归；其 BLE/板端应答是模拟数据，不代表手机或 FPGA 实物验收。

无需改动 RTL、重新 P&R 或烧录即可使用本机练习。Android 页面共用实现，APK 安装是单独的交付步骤。
